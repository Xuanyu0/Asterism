
# 核心价值主张：

* 帮助学习者建立自己的学习状态模型。
* 让 AI 基于真实的学习状态提供辅助。

# 用户

## 第一个用户

* 我自己

## 目标用户

* 研究型自学者
* 长期研究者
* 教育设计者/工作者
* AI重度用户
* 多路线，多方向自学者

## 非目标用户

* 轻度学习者
* 普通笔记用户

# 解决的问题

## 核心问题：学习状态不可见、难以记录

问题解决后应：
* 当前学习状态清晰可见：
  * 让用户知道当前“我不知道什么”
  * 记录“我曾经怀疑过的东西”
  * 知道”我应该按照什么路径学习“

## 学习状态无法清晰地阶段性推进

问题解决后应：
* 能够阶段性有成果地，清晰可见地推进学习进度
* 保持低认知负担的前提下，看到当前的认知大体状况

## AI对于个人学习以及认知的介入不可见、不可控

问题解决后应：
* 对AI之于个人学习的介入享用绝对主权

# 为什么 2026 年这个产品成立？

我的答案会是：

* 可以得到知识已经极度丰富
* 生成式 AI 已经极度强大
* 但学习者对自身学习状态的理解仍然极其模糊
* 学习者可能不知道自己 需要/想要 学习什么
