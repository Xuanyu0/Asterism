# 竞品分析：Asterism 与同类产品的定位对比

> 基于 2026 年 7 月对开源项目（GitHub）和闭源产品的公开资料调研。
> 调研方式：逐产品阅读官方网站、README、设计文档、创始人博客，获取一手定位声明。

---

## 一、定位光谱：所有产品按"管理什么"分层

从"管理知识内容"到"管理学习状态"，越靠右越接近 Asterism：

```
管理知识内容                        管理理解过程                管理学习状态
──────────────────────────────────────────────────────────────────────────→
```

| 层 | 管理对象 | 产品 | 官方定位（原文引用） |
|----|---------|------|-------------------|
| **内容存储** | 笔记、文件、书签 | Obsidian | *"Sharpen your thinking"* / *"The free and flexible app for your private thoughts"* |
| | | Roam Research | *"A note-taking tool for networked thought"* |
| | | Reflect | *"Think better with Reflect"* / *"Never miss a note, idea or connection"* |
| | | myMind | *"Remember everything. Organize nothing."* |
| | | Milanote | *"Get organized. Stay creative."* — 创意项目管理 |
| **结构化对象** | 类型化实体 + 关系 | Capacities | *"A studio for your mind"* / *"A home for everything you think, learn, and create"* — 对象优先笔记 |
| | | Tana (outliner) | Supertag 类型化节点，无限大纲 + 视图（表格/看板/日历） |
| **关系/系统** | 外部系统的结构 | Kumu | *"Make sense of your messy world"* — 利益相关者映射、系统映射、因果循环图 |
| **理解过程** | 对复杂主题的掌握 | Heptabase | *"Master anything you learn"* / *"create a world where anyone can effectively establish a deep understanding of anything"* |
| | | Scrintal | *"Think visually, learn deeply"* |
| **学习状态** | 你与知识之间的认知状态 | **Asterism（唯一）** | *"管理学习者与知识之间的学习状态，而不是认知/知识本身"* |

## 二、开源项目对比

来自 GitHub 上定位最接近的 8 个项目，按相关性排序。

### 第一梯队：高度相关

| 项目 | 定位 | Stars | 与 Asterism 的核心差异 |
|------|------|-------|----------------------|
| **Heartwood** | *"Not a note-taking app — a system that compounds understanding across every run"*，带推理引擎的个人知识图谱 | 新项目 | 理念最接近（"理解累积"），但将图谱操作全部押注在 LLM 推理管道上，非用户驱动 |
| **Memory Map** | *"Your knowledge organizes itself… shows you what you have been thinking about"* | ~7 | 组织权交给 LLM（Claude 决定创建/更新什么），Asterism 用户通过工具主动操作 |
| **NoteConnection** | *"Unlocks the structure of your knowledge… transforms Markdown into directed knowledge graphs and learning paths"* | npm 已发布 | 聚焦学习路径 + DAG 层次结构，有课程生成能力；关系是**推断**出来的，非用户显式触发 |
| **Nexus SSMT** | *"Transform scattered lecture notes into interactive visual Knowledge Graph"* — 面向学生的社交学习图谱 | 新项目 | 唯一面向学生，核心是"主题 A 是 B 的先决条件"，以协作为中心 |
| **Loci** | *"Personal knowledge map… with automatic flashcard generation and spaced repetition"* | 新项目 | 图谱 + 间隔重复（FSRS）结合，目标是记忆保持而非理解状态的形式化表达 |
| **org-roam-ui** | *"A graphical frontend for exploring your org-roam Zettelkasten"* | **~2,250** | 纯粹只读可视化，无图谱操作、无认知操作、无独立引擎 |
| **knowledge-worker** | *"Personal knowledge graph that survives between AI conversations… User-centered, not conversation-centered"* | PyPI 已发布 | 以溯源为重心的 AI 记忆，人类审核作为 LLM 提议的守门人 |
| **Brian** | *"Personal Knowledge Base with vector-based similarity search and beautiful graph visualization"* | 新项目 | 传统 PKM（第二大脑），图谱连接由 TF-IDF 余弦相似度自动计算 |

### 第二梯队：中等相关

| 项目 | 定位 | 相似之处 | 差距 |
|------|------|---------|------|
| **zk-graph-view / zkviz** | Zettelkasten 笔记网络可视化 | Zettelkasten 原子笔记哲学相同 | 仅是可视化工具，无认知操作 |
| **Freeplane / WiseMapping** | 成熟开源思维导图（4,169 stars） | 概念映射方向正确 | 树状结构 ≠ 自由图谱，无学习状态管理 |
| **Cognitext** (Emory NLP) | 维基百科 → 概念图生成器 | 概念图方向对 | 针对第三方内容，非个人认知状态 |

## 三、闭源产品对比

| 产品 | 官方定位 | 核心功能 | 认知操作？ | 关键差异 |
|------|---------|---------|----------|---------|
| **Heptabase** | *"Master anything you learn"* — 白板 + 卡片 + AI 导师 | 嵌套白板、分区、箭头连接、标签属性、AI 课程 | ❌ 无。用户手动拖拽分拆 | 最接近的竞品。但管理的是"深度理解"（知识内容），而非学习状态。Apple 级别设计。 |
| **Scrintal** | *"Think visually, learn deeply"* — 无限画布 + 区块 + 箭头 | 区块可转文档、AI 助手、协作 | ❌ 无 | 功能丰富的学习画布，仍关管理想法内容 |
| **Obsidian** | *"Sharpen your thinking"* — 本地 Markdown + Graph 视图 + Canvas + 插件 | 2250+ 插件，全局/局部图谱，Canvas | ❌ 无 | 关于管理笔记/知识，有出色的图谱可视化。Asterism 的"Asterism 是只读投影"规则与之完全一致。 |
| **Roam Research** | *"A note-taking tool for networked thought"* — 块级大纲 + 双向链接 | 每日笔记、块引用、页面引用、图谱视图 | ❌ 无 | 双向链接的发明者。图谱是被动观察工具。 |
| **Capacities** | *"A studio for your mind"* — 对象优先笔记 | 类型化对象、反向链接、AI 隐式链接发现 | ❌ 无 | 对象有类型（类 NodeRole），但目的是组织内容，非跟踪学习状态 |
| **Tana** | Supertag 类型化大纲，无限大纲 + 视图 | 节点引用（一处更新处处同步）、实时搜索 | ❌ 有**提案系统**（验证 → 应用），概念上与 Asterism 的 applyBatch 相似 | 但关于组织协作/决策，非个人认知。提案系统用于 AI 内容审批，非图转换。 |
| **Reflect** | *"Think better with Reflect"* — 端到端加密笔记 + AI | GPT-4 集成、日历集成、快速捕获 | ❌ 无 | 优雅快速的笔记应用，有 AI。 |
| **Kumu** | *"Make sense of your messy world"* — 关系映射 | 系统映射、因果循环图、利益相关者映射、透视图 | ❌ 无 | 关于理解外部系统，非内部学习状态 |
| **Milanote** | *"Get organized. Stay creative."* — 创意项目画板 | 情绪板、项目组织、团队协作 | ❌ 无 | 创意项目管理，非学习/认知 |
| **myMind** | *"Remember everything. Organize nothing."* — 一键保存 | AI 自动分类、关联搜索、无文件夹 | ❌ 无 | 书签/灵感捕获工具，非知识管理 |

## 四、关键结论

### 1. Asterism 的产品定位是唯一的

没有任何产品（开源或闭源）管理"学习状态"而非"知识内容"。最接近的 Heptabase 管理"深度理解"——但仍然是你对主题的理解**内容**（你读过的论文、写过的卡片），而非你与知识之间的**状态**（这部分的盲区在哪？新概念怎么整合？）。

### 2. 认知操作是 Asterism 独有的

所有竞品在"操作知识结构"层面只支持：增/删/改节点和边、手动排列位置、标记关系类型。没有任何产品有 **deconstruct（解构为子概念）**、**induce（归纳为抽象）**、**internalize（内化到现有结构）**、**diverge（发散到另一张图）** 这类结构化的、可撤销的、基于规则的图转换操作。

### 3. Asterism 最大的薄弱环节在 UX 和完成度

与 Obsidian（2250+ 插件）、Heptabase（Apple 级别设计）相比，Asterism 目前：
- 缺少低门槛的内容导入（Markdown → 图谱）
- 缺少流畅的阅读/写作体验
- 界面停留在"功能可用"阶段
- 无 AI 辅助

这些是 Phase 3（UI 迭代）和 Phase 4（AI Runtime）要做的事。架构上 Asterism 比上述所有竞品都更清晰，产品定位上独一无二，核心差距在**执行面和产品完成度**。

### 4. 与 Heptabase 的差异是最值得关注的

| 维度 | Heptabase | Asterism |
|------|-----------|----------|
| 核心隐喻 | 白板 + 卡片 | 图谱 + 工具 |
| 操作方式 | 手动拖拽、画箭头 | 工具构造原子操作 |
| 认知操作 | ❌ 无 | ✅ deconstruct / induce / internalize / diverge |
| 撤销 | 有但未公开 | ✅ 树形操作日志，replayToStep |
| 数据模型 | 白板/卡片/箭头，无正式 schema | ✅ 强类型 GraphData |
| 开放格式 | ❌ 闭源 | ✅ localStorage，未来开放 |
| AI | ✅ AI 导师已落地 | ⏳ Phase 4 |
| 设计 | Apple 级别 | MVP 阶段 |

**Heptabase 的强项（UX、AI）是 Asterism 的弱项；Asterism 的强项（形式化操作、引擎架构、撤销模型）是 Heptabase 的空白。**
