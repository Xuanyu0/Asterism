# UI设计

## 总体指导

* 低认知负担
* 高空间沉浸感
* 图谱主要
* AI 次要
* 操作模式明确
* UI 视觉设计“可插拔”

## Button设计

* （借鉴*Not Oxygen Include*）右上角有一个视图（ $Overlay$ ）的浮空Button
  * 图标：眼睛
  * 包含：
  * 沉浸浏览
    * 点击后隐藏所有UI，让用户专注于浏览知识图谱
    * 此沉浸模式下：鼠标移动到边缘， UI 才重新浮现
  * Notebook视图
    * 仅高亮有实际笔记的节点
    * 无笔记的节点半透明
  * 未掌握视图
    * 仅“实化”（视觉效果）虚节点和无向虚边
    * 半透明其他节点与边
  * 知识群视图


* 左上角有切换模式的浮空Button（在对应模式下显示对应图标）
  * 点击一下在两种交互模式间切换
  * 在其下竖直排列对应模式下所有的操作
    * 点击对应操作鼠标光标改变
    * 鼠标右键一键回到默认模式
* 右下角有AI模式开关（灯泡图标）
  * 点击展开后有“翻译”和“翻译并分析”两个选项Button
  * 展开后Button周围背景有淡彩色渐变流动辉光

## 导航卡片设计

### 存在的地方

* 主知识图谱
* 子图
* 笔记库
* 常识层

不存在于单轮学习中

### 三种状态

#### Dock

* 包含功能：
  * 逐级返回主图：每次返回，自动跳转到上一级抽象节点所属子图，直到进入主知识图谱
  * 当前图内搜索：根据文本信息自动匹配对应节点或边的标签
  * 主知识图谱的logo：点击一键返回主知识图谱
  * 当前所在位置：当前子图路径（常识层也算子图，笔记库也算主图附属，但实际上是传统文本库UI设计，而不是图的表现形式）
    * 显示方式如：主图 -> 子图1 -> 子图2 -> $\dots$
    * 限制：如果dock显示不下则当前子图名称置于最右端，左端显示不下的部分淡化
    * 完整显示方法：如果显示不下，鼠标悬浮在其上，路径才会自动拓展到dock外，完整显示全部路径名称
  * 展开按钮：导航卡片用来展开到Expand状态
#### Expand

* 包含功能：
  * 逐级返回主图
  * 主知识图谱的logo
  * 主知识图谱名称：
    * 功能：点击后在卡片外侧边展开所有主知识图谱的列表，同时列表中心的箭头指向当前浏览的图谱（类似垂直卷轴）
    * 如果用户通过点击或滑动或鼠标滚轮滚动的方式改变了中心箭头的指向，则在用户二次确认后自动切换到对应的主知识图谱
  * 当前主知识图谱内全局概览且点击可跳转
    * 方式：cytoscape局部内嵌窗口渲染抽象树
    * 抽象树：主知识图谱作为根节点，其他节点必须是抽象节点
    * 点击抽象树上任意节点即可跳转到对应子图
    * 用户所在节点，对其节点做边缘光亮标记，同时初始视图中相机聚焦于该节点
  * 当前主知识图谱内全局搜索
    * 功能：快速在全局范围内查找标签与摘要，并返回对应抽象树上从根节点到对应目标的路径
    * 返回形式如：主知识图谱名称 -> 抽象节点1 -> 目标节点
  * 进入笔记库（当前知识图谱）
  * 进入常识层（当前知识图谱）
  * 创建新的主知识图谱
  * 设置按钮
    * 功能：新开窗口，跳转到设置页面
  * 折叠按钮：导航卡片用来折叠会dock状态


#### Hidden

* 沉浸模式下自动吸附在侧边并隐藏
* 直到用户关闭沉浸模式才显示

## 视觉设计

* 所有操作 Button：
  * 半透明
  * 浮空
  * 自动淡化（pointer 离开Button 3s 后自动淡化）
  * 边缘吸附（吸附在屏幕边缘或侧边栏旁）
* Button展开动效：滑动弹出（300ms）
* Button收起动效：滑动收入（300ms）

# 笔记库设计

* 所有笔记持久化储存在本地
* 进入方式：
  * 导航卡片直接跳转到主知识图谱的笔记库
  * 知识节点浮空窗链接跳转

## UI设计（MVP阶段）

* 设计指导：界面轻量化设计，笔记地址与知识图谱上节点地址绑定
* 总体布局： 
  * 左栏为对应知识图谱在笔记层的镜像投影（只作为视觉显示，不跳出浮空窗编辑图上节点/边属性）
    * 节点可交互：此时点击知识图谱上的节点，右栏自动跳转出对应笔记（若没有笔记，则为空）
  * 右栏编辑区
    * 界面极简设计：仅包含分栏预览md文件选项和编辑页面
* 导航卡片的“抽象树”此时切换为笔记库的导航状态（直到退出笔记库，才恢复为原来的导航状态）
