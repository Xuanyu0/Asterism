# 前端知识学习清单

按重要程度排列，面向有通用编程背景（如 C++）、无前端经验的开发者。

---

## 第一梯队：不掌握则无法读懂代码

### 1. TypeScript 类型系统
- interface / type / 可选字段 `?:`
- Union type（`A | B`）、Discriminated union（通过 `role` 字段判别）
- Generics 基础（`Ref<T>`、`Array<T>`）
- **参考资料**：TypeScript Handbook（Interfaces / Union Types / Discriminated Union 三节）

### 2. ES Module（import / export）
- 具名导出 `export const/interface`、默认导出 `export default`
- 类型导入 `import type`
- **参考资料**：红宝书第 26 章（模块）

### 3. 变量声明与箭头函数
- `const` / `let`、块作用域、暂时性死区
- 箭头函数语法、无 `this` 绑定
- **参考资料**：红宝书第 3 章 §3.3（变量声明）、第 10 章 §10.2（箭头函数）

### 4. 对象字面量与解构
- 对象字面量构造、简写属性 `{ x, y }`
- 解构赋值 `const { cy } = obj`
- **参考资料**：红宝书第 3 章 §3.4（Object 类型）、第 4 章 §4.1.5（解构）、第 8 章 §8.1（理解对象）

---

## 第二梯队：理解架构和数据流所必需

### 5. 闭包与高阶函数
- 作用域链、闭包中变量的生命周期
- 函数返回函数模式（本项目 Runtime 模块的核心模式）
- **参考资料**：红宝书第 4 章 §4.1.4（作用域链）、第 10 章 §10.14（闭包）

### 6. Vue 3 响应式系统
- `ref()` 包装原始值、`.value` 访问、`ref<DOM>(null)` 模板引用
- `computed()` 自动追踪依赖的缓存计算属性
- `watch(source, callback, { deep: true })` 响应式观察者
- 底层依赖 Proxy → **参考资料**：红宝书第 9 章（代理与反射）
- **参考资料**：Vue 3 官方文档（Reactivity Fundamentals / Computed / Watchers）

### 7. Pinia Store 模式
- `defineStore(id, { state, actions })`、`useXxxStore()` 获取单例
- state 是工厂函数、actions 通过 `this` 直接修改
- **参考资料**：Pinia 官方文档（Getting Started / Defining a Store）

### 8. TypeScript `as` 类型断言
- `value as Type` 语法、用途与风险
- **参考资料**：TypeScript Handbook（Type Assertions）

---

## 第三梯队：理解具体语法细节

### 9. null / undefined 与可选链
- null vs undefined 语义差异
- `?.` 可选链、`??` 空值合并运算符
- **参考资料**：红宝书第 3 章 §3.4（Undefined / Null）、第 4 章 §4.4（可选链）

### 10. Vue 生命周期钩子
- `onMounted`（DOM 就绪）、`onBeforeUnmount`（组件销毁前清理）
- **参考资料**：Vue 3 官方文档（Lifecycle Hooks）

### 11. Vue 单文件组件（SFC）结构
- `<template>` / `<script setup>` / `<style scoped>` 三段式
- `<script setup>` 编译期自动暴露顶层变量
- **参考资料**：Vue 3 官方文档（Single-File Component / `<script setup>`）

### 12. Vue 模板绑定语法
- `v-if` 条件渲染、`:class` 动态 CSS
- `@click` / `@contextmenu.prevent` 事件绑定
- `ref="xxx"` DOM 引用绑定
- **参考资料**：红宝书第 14 章（DOM） + 第 17 章（事件）理解底层机制；Vue 3 官方文档（Template Syntax）

---

## 建议学习路线

```
红宝书第 3 章 → 第 4 章 → 第 10 章 → 第 26 章 → 第 9 章
    (变量/类型)   (作用域/解构)  (闭包)    (模块)   (Proxy)
                                                        ↓
                                                Vue 3 官方文档
                                          (响应式 / 生命周期 / SFC / 模板)
                                                        ↓
                                              TypeScript Handbook
                                          (Interfaces / Unions / Discriminated Union)
                                                        ↓
                                              Pinia 官方文档
```

单个概念的详细讲解不在本文档范围内。遇到具体代码看不明白时，先定位它属于上述哪个概念，再针对性查对应参考资料。
