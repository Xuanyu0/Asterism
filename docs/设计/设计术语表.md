# 设计术语表

> 本表服务对象：`docs/设计/`（L1 产品 spec）的阅读、写作与翻译。
>
> 说明：`设计/ + 代码` 来源的条目仅收录概念部分（中文 + 英文翻译 + 定义），其代码标识符见 `docs/开发文档/开发术语表.md`。

## 编写规则

1. **字段格式**：每行统一为 `中文 | 英文翻译 | 定义` 三列。
2. **英文翻译**：英文自然语言翻译，**不是代码标识符**。代码标识符一律不进本表，请查 `docs/开发文档/开发术语表.md`。
3. **术语来源**：默认术语直接来源于 `docs/设计/` 下的文档（L1）。
4. **用途**：连接中文设计术语与英文翻译，服务设计文档的阅读、写作与翻译。
5. **列缺失**：某一列确无内容时用 `-` 标记缺失，并用 `()` 注明理由（如 `-（未定译名）`）。

## 一、前端概念

| 中文           | 英文翻译                 | 定义                                                       |
| -------------- | ------------------------ | ---------------------------------------------------------- |
| 交互模式       | interaction mode         | 三种主交互模式（默认 / 认知 / 布局），决定画布点击行为的语义 |
| 默认模式       | default mode             | 无操作选中时的空闲模式，点击节点弹出浮空窗                 |
| 认知模式       | cognition mode           | 认知演化操作模式，点击节点触发认知操作                     |
| 布局模式       | arrangement mode         | 布局操作模式，点击节点选择为操作对象                       |
| 常驻操作       | permanent operations     | 不依赖模式的永久可见操作（9 个按钮）                       |
| 右键取消       | right-click cancel       | 全局退出机制：清除当前工具选择 + 放弃所有草稿              |
| 导航卡片       | navigation card          | 图谱层级导航 UI（Dock / Expand / Hidden 三态）             |
| 预览           | preview                  | 确认前在画布临时渲染位置，不写入 GraphData                 |
| 多选 / 框选    | multi-selection          | 多个节点同时选中的交互机制（当前代码中尚未实现）           |

## 二、GraphEngine 概念

### 核心概念

| 中文         | 英文翻译         | 定义                                                               |
| ------------ | ---------------- | ------------------------------------------------------------------ |
| 图数据       | graph data       | 系统的唯一事实源，包含节点列表 + 边列表 + 图元信息                 |
| 节点         | node             | 图中的知识单元，按角色（知识节点 / 引用节点）分型                  |
| 边           | edge             | 知识间关系的表示，由确定性 × 方向性两个维度确定                    |
| 知识节点     | knowledge node   | 表达知识的本体                                                     |
| 引用节点     | reference node   | 原节点在其他图中的代理/投影                                        |
| 实节点       | real node        | 已掌握的知识节点                                                   |
| 虚节点       | virtual node     | 未掌握的知识节点，圆形，固定半径 r₀                                |
| 原子节点     | atomic node      | 基础实节点，圆形，不可再分                                         |
| 抽象节点     | abstract node    | 拥有子图的实节点，正多边形，边数 = 抽象等级 + 2                    |
| 沟通节点     | communication node | 子图中联系父图的引用节点                                         |
| 启发节点     | heuristic node   | 通过发散操作创建的跨图引用节点                                     |
| 度数         | degree           | 节点连接的边数，决定节点质量进而决定节点大小 |
| 认知抽象等级 | abstraction level | 内部最大子图层数，系统决定，用户不可改                             |
| 图类型       | graph kind       | 图的四种类型（根图谱 / 子图 / 知识块 / 常识层）                    |
| 根图谱       | root graph       | 无父图，整个知识系统的根                                           |
| 子图         | subgraph         | 抽象节点内部的展开                                                 |
| 知识块       | learning block   | 单轮学习的临时游离产物                                             |
| 常识层       | common layer     | 已内化的知识集合，仅含节点，无边                                   |
| 认知状态     | cognitive state  | 折叠/展开标记，持久化为 GraphData 的一部分                        |
| 节点质量       | node mass                | 边宽公式中的节点质量参数，$m = 1 + \text{degree}$          |


### 边

| 中文     | 英文翻译                 | 定义                                     |
| -------- | ------------------------ | ---------------------------------------- |
| 有向实边 | directed real edge       | A → B，B 依赖于 A 作为前置知识。禁止成环 |
| 有向虚边 | directed virtual edge    | A -·→ B，启发联想。不参与环检测          |
| 无向实边 | undirected real edge     | A — B，明确相关，无方向                  |
| 无向虚边 | undirected virtual edge  | A -·- B，待发掘的关联。唯一非终态边类型  |

### 认知操作

| 中文          | 英文翻译      | 定义                                          |
| ------------- | ------------- | --------------------------------------------- |
| 解构          | deconstruct   | 原子实节点 → 抽象节点 + 空子图                |
| 归纳          | induce        | 多节点 → 新抽象节点 + 子图 + 沟通节点/边      |
| 内化 / 常识化 | internalize   | 节点从原图转移至常识层                        |
| 发散          | diverge       | 跨图创建启发节点 + 有向虚边（三种情况）       |
| 探索          | explore       | 开启单轮 AI 学习，产出知识块（MVP 后实现）    |
| 发掘          | unearth       | 对虚节点/无向虚边开启学习并替换（MVP 后实现） |

### 布局操作

| 中文     | 英文翻译       | 定义                          |
| -------- | -------------- | ----------------------------- |
| 移动     | move           | 单节点拾取放置移动 + 碰撞检测 |
| 调整距离 | adjust distance| 沿两节点连线方向连续调整边长  |
| 调整轨道 | adjust orbit   | 离散轨道吸附 + 角度调整       |
| 环绕布局 | orbit layout   | 一组节点环绕中心节点排列      |
| 路径布局 | path layout    | 一组节点沿直线排列            |
| 云布局   | cloud layout   | 节点随机聚集分布（非 MVP）    |

### 操作日志与回溯

| 中文     | 英文翻译  | 定义                                                       |
| -------- | --------- | ---------------------------------------------------------- |
| 批       | batch     | 一次提交调用的全部操作 = 一条日志 entry = 一次回溯单元     |
| 游标     | cursor    | 当前操作日志位置，undo/redo 沿树移动                       |
| 时间跳跃 | time leap | 沿操作日志树路径跳到目标批次（待规划）                     |

## 三、AI 术语

| 中文       | 英文翻译               | 定义                                           |
| ---------- | ---------------------- | ---------------------------------------------- |
| 协作器     | Collabrator            | AI 实体统一名称（替代 "Agent"），后端实现      |
| 助手       | Assistant              | Human-led + internal 认知源，回答/处理人类问题 |
| 分析师     | Analyst                | Human-led + external 认知源，解析外部资料      |
| 提示器     | Prompter               | AI-led + internal 认知源，主动分析并提见解     |
| 构建器     | Builder                | AI-led + external 认知源，模拟用户构建图谱     |
| 单轮学习   | single learning session | 一次 AI 辅助学习对话的完整过程                 |
| 常识化考验 | common-sense test      | 内化前 AI 生成的验证题集                       |

## 四、规则分类术语

| 中文       | 英文翻译    | 定义                                                                     |
| ---------- | ----------- | ------------------------------------------------------------------------ |
| 规则       | rule        | 判断系统状态的约束条件，由分类 × 应用时机 × 触发时机三个维度定义         |
| 硬性规则   | hard rule   | 由编程语言/计算机自动保证的规则。                                        |
| 自定义规则 | custom rule | 由产品设计者定义或程序员承诺的规则。                                     |
| 全局规则   | global rule | 针对 GraphData 元素的不变量，一处定义，所有操作自动遵守。                |
| 局部规则   | local rule  | 与特定操作或功能绑定的规则。                                             |
| 内联规则   | inline rule | 局部规则的子类——硬编码在功能代码中，不需要灵活开关。                    |
| 非内联规则 | non-inline rule | 局部规则的子类——独立定义且可复用，需要灵活开关或跨操作泛用。         |
