# 操作回溯

## 原则

- 完整记录用户所有的操作历史

## 操作日志数据模型

- 操作日志的数据结构: **树**
- 一条操作日志记录**一次完整的多图/单图操作**

## 概念

- 操作节点：一条操作日志
- undo：撤销一次操作，返回到上一个操作节点
- redo：撤销(一次撤销操作)，回到撤销前的状态
- 时间跳跃：从用户当前操作节点跳跃到目标操作节点
- 新操作：用户执行一次完整的多图/单图操作
- 操作日志侧边栏：可视化操作日志的地方

## 机制

- 只要用户执行一次新操作就会产生一个新的叶子节点
- undo 永远返回上一级操作节点
- redo 永远只在运行时执行过 undo 时有效

## UI 设计

### 原则

- 节点样式统一用纯色色块

### 可视化树显示

#### 形式

- 显示在右侧边栏
- 不允许zoomin/zoomout，固定视口大小
- 拖拽移动
- 鼠标滚轮滚动实现上下翻页浏览

#### 呼出方式

- 点击吸附在右侧屏幕边缘的三角边框箭头按钮
- 呼出后推挤主画布（参考 F12 呼出控制台）

### 节点

#### 排列方式

- 新的操作永远挂在同层右侧，添加后重新以近似对称布局
- 布局：以父节点所在垂线为对称轴大致成扇形

#### 原子操作

- 配色参考 git：
  - 添加（添加节点/边）：绿色小圆点
  - 删除：红色小圆点
  - 更新：橙色小圆点
- 折叠：紫色小圆点
- 移动：灰色小圆点

#### 组合式操作

- 认知工具操作：黄色四角星
- 布局工具操作：蓝色正方形

#### 节点图例提示

- 绘制在操作日志侧边栏左下方

### 边

- 统一使用二次贝塞尔曲线
  - 只有一个子节点时：控制点放中间，表现为直线
  - 多个子节点：父节点左侧边往左弯曲，右侧往右弯曲

## UX 设计

- 用户单击节点在右侧展开一个显示详细的浮空标签卡片
  - 浮空卡片样式：左边三角形，指向节点，整体形状为圆角矩形
  - 浮空卡片永远处于选中的节点的右侧并跟随节点位移
- 用户双击节点自动进行时间跳跃
  - 跳跃过程中按顺序播放具体的操作过程图的变化状况，而不是瞬间完成
