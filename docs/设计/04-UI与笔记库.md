# UI设计

## 总体指导

- 低认知负担
- 高空间沉浸感
- 图谱主要
- AI 次要
- UI不挤占空间
- 基本不采用分栏式UI
- 操作模式明确
- UI 视觉设计“可插拔”

## Button设计

- （借鉴*Not Oxygen Include*）右上角有一个视图（ $Overlay$ ）的浮空Button
  - 图标：眼睛
  - 包含：
  - 沉浸浏览
    - 点击后隐藏所有UI，让用户专注于浏览图谱
    - 此沉浸模式下：鼠标移动到边缘， UI 才重新浮现
  - Notebook视图
    - 仅高亮有实际笔记的节点
    - 无笔记的节点半透明
  - 未掌握视图
    - 仅“实化”（视觉效果）虚节点和无向虚边
    - 半透明其他节点与边
  - 知识群聚焦视图
    - 在此视图下，非鼠标属于所在知识群的节点自动半透明化
  - 抽象树总览视图
    - 主画布切换渲染当前根图谱的抽象树：根图谱作为根节点，其他节点必须是抽象节点
    - 点击抽象树上任意节点即跳转到对应子图，跳转后退出视图
    - 用户所在节点做边缘光亮标记，进入视图时相机聚焦于该节点

- 左上角有切换模式的浮空Button（在对应模式下显示对应图标）
  - 点击一下在两种交互模式间切换
  - 在其下竖直排列对应模式下所有的子操作
    - 点击对应操作鼠标光标改变为对应操作下的光标样式
    - 鼠标右键一键取消所有选中工具，并回到默认模式（即当前没有任何工具选中）
- 右下角有AI模式开关（灯泡图标）
  - 点击展开后有“翻译”和“翻译并分析”两个选项Button
  - 展开后Button周围背景有淡彩色渐变流动辉光

## 导航卡片设计

### 存在的地方

- 根图谱
- 子图
- 笔记库
- 常识层

不存在于单轮学习中

### 三种状态

#### Dock

- 以 Dock 的形式简要呈现功能按钮与信息
- 对 对应的功能按钮加上鼠标悬浮提示信息
- 包含功能：
  - 逐级返回根图谱：每次返回，自动跳转到上一级抽象节点所属子图，直到进入根图谱
  - 根图谱的图标：轻击一键返回根图谱
  - 当前所在位置：当前子图路径（常识层也算子图）
    - 显示方式如：根图谱 > 子图1 > 子图2（对应的名称点击也可跳转）
    - 限制：如果dock显示不下则当前子图名称置于最右端，左端显示不下的部分淡化
  - 搜索按钮：展开统一搜索面板
  - 展开按钮：展开全局导航 Panel
- 按钮排布：局部作用域按钮（搜索）紧邻路径显示，全局作用域按钮（展开）位于 Dock 最右端，以位置区分作用域。展开按钮和搜索按钮中间隔一条杠

#### Expand

- 以 面板 的形式展开对应的功能面板
  - 点击搜索按钮展开统一搜索面板
  - 点击展开按钮展开全局导航 面板
- 统一搜索面板：
  - 搜索范围：当前根图谱（当前图 + 其所有子图，不含其他根图谱）
  - 只有一个搜索框；结果按范围分组：当前图 / 当前根图谱的其他子图
  - 其他子图的结果附带所在路径，返回形式如：根图谱名称 > 抽象节点1 > 目标节点
  - 点击结果：跳转到对应图并定位对应节点 / 边
  - 匹配逻辑由 GraphEngine 统一实现：大小写不敏感，匹配节点与边的标签
- 全局导航面板：
  - 根图谱名称：
    - 点击即跳转到对应的根图谱
  - 进入笔记库页面（优先跳转到当前图谱对应的页面）
  - 进入常识层页面（同上）
  - 创建新的根图谱
  - 设置按钮
    - 功能：新开窗口，跳转到设置页面

#### Hidden

- 沉浸模式下自动吸附在侧边并隐藏

### 导航卡片的面板视觉设计

#### 总原则

- 动画体现面板从 Dock 边缘滑动生长出来
- 面板骨架统一
  - 骨架分为标题区和内容区（用一行浅横线分隔）

#### 详细设计

- 标题区
  - 统一搜索面板的标题区就是搜索框
    - 左侧带一个 12px 的 🔍 小图标
  - 全局导航面板标题区是一行文字：全部根图谱
- 内容区
  - 统一搜索面板为搜索结果
    - 搜索结果以当前图谱和当前根图谱的其他图谱进行分组（用浅横线分隔）
      - 每一组有对应组头（当前图谱/其他子图）
      - 当前图谱的搜索条目的右侧显示名称，其他子图的条目则显示路径
    - 所有搜索条目左侧以圆点或短线区分搜索结果的类型
    - 搜索得到的路径如果放不下则截断

## 总体视觉设计

- 所有操作 Button：
  - 半透明
  - 浮空
  - 自动淡化（pointer 离开Button 3s 后自动淡化）
  - 边缘吸附（吸附在屏幕边缘或侧边栏旁）
- Button展开动效：滑动弹出（300ms）
- Button收起动效：滑动收入（300ms）

# 笔记库设计

- 所有笔记持久化储存在本地
- 进入方式：
  - 导航卡片直接跳转到根图谱的笔记库
  - 知识节点浮空窗链接跳转

## UI设计（MVP阶段）

- 设计指导：界面轻量化设计，笔记地址与图谱上节点地址绑定
- 总体布局：
  - 左栏为对应图谱在笔记层的镜像投影（只作为视觉显示，不跳出浮空窗编辑图上节点/边属性）
    - 节点可交互：此时点击图谱上的节点，右栏自动跳转出对应笔记（若没有笔记，则为空）
  - 右栏编辑区
    - 界面极简设计：仅包含分栏预览md文件选项和编辑页面
- 抽象树总览视图此时切换为笔记库的导航状态（直到退出笔记库，才恢复为原来的导航状态）
