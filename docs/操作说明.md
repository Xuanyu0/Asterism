# Asterism 操作说明

## 键盘快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+K` | 打开画布内搜索，输入关键词匹配当前图谱的节点/边 |
| `Esc` | 关闭导航面板或搜索面板 |
| `Enter` | 搜索框中按 Enter 直接选中第一条匹配结果 |

## 鼠标快捷操作

| 操作 | 作用 |
|------|------|
| 右键画布 | 取消当前工具，回到空闲状态 |
| 拖拽导航卡片六点手柄 | 自由摆放卡片位置，松手自动吸附最近边缘 |
| 点击卡片外部 | 关闭浮动面板（等价于 `Esc`） |
| 悬停路径条 | 截断的面包屑路径完整展开 |
| 悬停根图列表行 | 浮现删除按钮 |
| 再次点击删除工具目标 | 首次标记（红色高亮），再次确认删除 |
| 再次点击根图删除按钮 | 首次蓄力（按钮变"确认"），再次级联删除整个根图 |

## 自动行为

| 行为 | 说明 |
|------|------|
| 3s 自动淡化 | 鼠标离开导航卡片 3 秒后变淡，移回或打开面板恢复 |
| 面板方向自适应 | 卡片在屏幕下半部时，面板向上展开 |
| 画布定位动画 | 搜索选中后画布飞到目标并高亮闪烁 1.2s |
