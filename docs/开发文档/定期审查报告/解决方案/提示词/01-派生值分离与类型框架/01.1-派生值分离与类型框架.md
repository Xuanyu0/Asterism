# 01.1-派生值分离与类型框架 — 提示词

## 当前状态

GraphData 类型（`packages/graph-engine/src/types/graph_data.ts`）中 `form` / `abstractionLevel` 是存储字段：

- `NodeBase.abstractionLevel: number`（graph_data.ts）——死字段，引擎零消费，deconstruct/induce 从不递增，始终 = 0
- `KnowledgeNodeData.form?: RealNodeForm`（graph_data.ts）——存储字段，被 deconstruct / internalize 消费（form 检查）

不变量：`form === 'abstract' ⟺ childGraphId !== undefined`（deconstruct/induce 总是同时设置两者）。权威源 = `childGraphId`（子图结构）。

本次改造目标：将两者改为**运行时派生值**——从类型移除字段，引擎提供派生函数，消费方改接派生。派生值不持久化，读取时计算。

## 目标

完成后，GraphData 类型只含事实数据（结构 + 用户数据），`form` / `abstractionLevel` 由 `core/derive.ts` 的纯函数在读取时推导。引擎内部所有读写这两个字段的地方迁移完毕，GE 测试全绿。

## 架构变更

```
旧：
graph_data.ts: NodeBase.abstractionLevel + KnowledgeNodeData.form（存储字段）
    ↓ 写入方：deconstruct / induce / diverge / internalize（设置字段）
    ↓ 读取方：deconstruct / internalize（form 检查）

新：
graph_data.ts: 移除两个字段，定义派生契约签名（DeriveNodeForm / DeriveAbstractionLevel）
core/derive.ts: 派生函数实现（读取时计算，不持久化）
    ↓ 消费方：deconstruct / internalize 改接 deriveNodeForm
    ↓ 写入方：删除全部 form / abstractionLevel 写入
```

## 具体子任务

### 1.1. 类型契约（graph_data.ts）

- 移除 `NodeBase.abstractionLevel` 字段。
- 移除 `KnowledgeNodeData.form` 字段。
- 定义派生契约签名类型（与数据接口同文件，文件级耦合）：

```ts
export type DeriveNodeForm = (node: KnowledgeNodeData) => RealNodeForm
export type DeriveAbstractionLevel = (
    lookupGraph: (graphId: GraphId) => GraphData | undefined,
    node: NodeBase,
) => number
```

- 更新文件头注释与相关字段注释：文档化派生规则——权威源 = `childGraphId`；`form === 'abstract' ⟺ childGraphId !== undefined`；`abstractionLevel` = 内部最大子图层数，空子图 = 1。

### 1.2. 派生实现（core/derive.ts 新增）

- `deriveNodeForm(node)`：`node.childGraphId !== undefined ? 'abstract' : 'atomic'`，O(1)。
- `deriveAbstractionLevel(lookupGraph, node)`：沿 `childGraphId` 链递归推导：
  - 无 `childGraphId` → 0（原子节点）
  - 有 `childGraphId` 但子图不可达（lookupGraph 返回 undefined）→ 1（防御，链中断）
  - 子图可达 → 子图内所有节点的 `deriveAbstractionLevel` 最大值 + 1（空子图 → 0 + 1 = 1 ✅）
  - 环防御：visited 集合防止循环引用
- 单元测试（`core/derive.test.ts` 新增）：原子节点 / 抽象节点（空子图 = 1）/ 深层链（多级嵌套）/ 子图不可达 / 环防御边界。

### 1.3. 导出（index.ts）

- 从 index.ts 导出 `deriveNodeForm` / `deriveAbstractionLevel`（公开 API）。
- 导出签名类型 `DeriveNodeForm` / `DeriveAbstractionLevel`（随 graph_data.ts 类型一并导出）。

### 2.1. 读取迁移（deconstruct.ts / internalize.ts）

- `deconstruct.ts`：form 检查（`targetNode.form === 'abstract'`）改接 `deriveNodeForm(targetNode)`。
- `internalize.ts`：全部 form 检查（`rn.node.form === 'abstract'` 等 4 处）改接 `deriveNodeForm(...)`。

### 2.2. 写入删除（deconstruct.ts / induce.ts / diverge.ts / internalize.ts）

- `deconstruct.ts`：删除 `form: 'abstract'` 与 `abstractionLevel: 0` 写入。
- `induce.ts`：删除 `form: 'abstract'` 与 `abstractionLevel: 0` 写入。
- `diverge.ts`：删除 `abstractionLevel: 0` 写入。
- `internalize.ts`：删除 `abstractionLevel: 0` 写入。

删除是安全的：派生函数会推导出与写入相同的值（deconstruct 空子图 → 1；induce 新节点 → 1；diverge/internalize 新节点无 childGraphId → 0/atomic）。

### 3.1. 验证

- `pnpm --filter @my-project/graph-engine test` 全绿。
- 派生函数单元测试覆盖：原子 / 抽象 / 空子图 / 深层链 / 环防御。
