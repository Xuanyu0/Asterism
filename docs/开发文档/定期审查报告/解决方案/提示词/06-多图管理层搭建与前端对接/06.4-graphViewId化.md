# 06.4-graphViewId 化 — 提示词

## 当前状态

- `graph_store.ts` 的 `graphView` 是**独立持有的响应式引用**（GraphData | null）：`commitBatchToGraphs` 中手动 `store.graphView = resultGraph` 同步，`loadGraphToView` 中 `store.graphView = ensureDefaultCognitiveState(graph)`
- 渲染层 `Graph.vue`：`syncFromGraphData(graphStore.graphView)`（无视图时跳过）与 watch 源 `graphStore.graphView`
- 前端多处消费 `graphStore.graphView`（工具、用例层、渲染层、导航卡片等）

前置：06.3 已完成，`graphRegistry` 为 shallowReactive 顶层属性（引用替换触发响应式）。

## 目标

- `graphView` 从"独立持有的引用"改为**派生 accessor**：按 `graphViewId`（响应式 ID）从注册表查询当前显示的图
- `graphViewId` 是唯一响应式状态（切换图时更新）；`graphView` 由 `graphViewId` + `graphRegistry` 共同派生——任一变化触发重新求值，**统一"图操作"（registry 引用替换）与"切换图"（graphViewId 变化）两个触发源**
- 渲染层渲染源改读派生 `graphView`

## 架构变更

```
旧：graphView（独立响应式引用）← 手动赋值（commitBatchToGraphs / loadGraphToView）
    渲染：watch(graphView) → syncFromGraphData(graphView)
新：graphViewId（响应式 ID）+ graphView（派生：registry.get(graphViewId)）
    渲染：watch 派生 graphView → syncFromGraphData（registry 或 graphViewId 任一变化触发）
```

## 具体子任务

### 4.1. graphView → graphViewId

- `graph_store.ts`：`graphViewId` 为响应式状态（GraphId | null），`graphView` 改为**派生 accessor**（getter：`graphViewId` 为空返回 null，否则从 `graphRegistry` 按 ID 查询）——消费方读 `store.graphView` 的代码保持可用
- 移除 `commitBatchToGraphs` / `loadGraphToView` 中手动赋值 `graphView` 的代码：
  - `loadGraphToView`：更新 `graphViewId`（而非赋值 graphView）
  - `commitBatchToGraphs`：不再需要同步 graphView（注册表引用替换后派生 graphView 自动更新）
- 检查依赖 `graphView` 引用比较（如 `graphView === someGraph` 或 `graphView.id`）的消费方，改为按 `graphViewId` 比较或从派生值取

### 4.2. 渲染层派生

- `Graph.vue`：`syncFromGraphData` 渲染源改为读派生 `graphView`；watch 依赖 `graphViewId` + `graphRegistry`（派生 graphView 自动建立依赖）
- 空视图语义保持：无当前图（graphViewId 为空）时不渲染，行为同现状

| 前端测试 | 适配 graphViewId 语义 | 修改 |

## 变更边界

**禁止修改**：

- `commitBatchToGraphs` / `undo` / `redo` / `loadGraphToView` 的**行为语义**（仅允许 graphView 更新方式改为派生的配套调整）
- `packages/graph-engine/` 全部
- `graphRegistry` 的引用替换机制（06.3 已定）

**禁止行为**：

- 不得在消费方手工缓存 graphView 旧引用（派生值必须随 graphViewId / registry 更新）
- 不得改变切换图的导航行为（breadcrumb、graphPath 派生等不受影响）

## 验收标准

- [ ] `graphViewId` 为响应式状态；`graphView` 为派生 accessor（按 ID 从 registry 查询），消费方 `store.graphView` 读取可用
- [ ] `loadGraphToView` 更新 graphViewId（不再手动赋值 graphView）；`commitBatchToGraphs` 无 graphView 手动同步
- [ ] 渲染层：图操作（registry 引用替换）与切换图（graphViewId 变化）均触发渲染更新（两触发源统一）
- [ ] 空视图语义保持（graphViewId 为空不渲染）
- [ ] `pnpm --filter frontend test` 全绿
- [ ] `vue-tsc --build` 无错误
