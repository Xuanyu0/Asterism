# 07.6 childGraphId 字段迁移（方案 B：迁移 + 解引用源节点）— 提示词

## 当前状态

`childGraphId` 当前定义在 `NodeBase`（通用区，graph_data.ts:108），所有节点（含引用节点）类型上都可携带。01 步骤的既有设计是"引用节点携带 childGraphId（从源节点复制）"，用于 `deriveAbstractionLevel` 对引用节点直接推导（几何跟随原节点的设计途径）。

**用户裁决（方案 B）**：将 `childGraphId` 从 `NodeBase` 迁移到 `KnowledgeNodeData`（只属于知识节点）；**引用节点的 abstractionLevel 改为解引用源节点推导**——保持"几何跟随原节点"设计意图，同时让类型诚实（引用节点不可能拥有子图）且 childGraphId 单一事实源（源节点）。

**关键现状（实证）**：
- `deriveNodeForm` 契约签名已是 `(node: KnowledgeNodeData) => RealNodeForm`（graph_data.ts:179）——只处理知识节点，迁移后零改动。
- `deriveAbstractionLevel` 契约签名 `(lookupGraph, node: NodeBase)`（graph_data.ts:187）——需扩展处理引用节点。
- 引用节点构造（induce/deconstruct）**实际未复制** childGraphId（01 设计未落地，本次不补）。
- `internalize.ts` 读 childGraphId 处均已先收窄 `role === 'knowledge'`。
- 既有单测 `derive.test.ts:163`"引用节点携带 childGraphId 时推导与知识节点一致"需重构为解引用语义。

## 目标

`childGraphId` 只存在于 `KnowledgeNodeData`；引用节点不携带该字段；`deriveAbstractionLevel` 对引用节点通过解引用源节点（sourceGraphId/sourceNodeId → 源节点 → 递归推导）返回正确抽象等级；几何跟随设计意图保留。

## 架构变更

```
旧：NodeBase.childGraphId?（通用区）→ 引用节点类型可携带（设计声称复制，实现未做）
    deriveAbstractionLevel(lookupGraph, node: NodeBase) → 引用节点直接读自身 childGraphId

新：KnowledgeNodeData.childGraphId?（仅知识节点）；ReferenceNodeData 无该字段
    deriveAbstractionLevel(lookupGraph, node: NodeData)
      ├─ knowledge：沿自身 childGraphId 链递归（现状逻辑）
      └─ reference：解引用源节点（lookupGraph(sourceGraphId) → nodes.find(sourceNodeId) → 递归推导）
                     源节点不可达 → 0（防御）
    递归内部（deriveLevel 遍历子图节点）：仅 knowledge 节点参与层级（引用节点跳过，贡献 0）
      ——避免沟通节点解引用成环（沟通节点指向父图，解引用会回到本子图）
```

## 具体子任务

### 1.1 类型迁移（graph_data.ts）

- `NodeBase` 删除 `childGraphId?: GraphId`。
- `KnowledgeNodeData` 增加 `childGraphId?: GraphId`。
- 注释更新：
  - NodeBase 的 `@remarks`（原"childGraphId 放在通用区的原因：引用节点创建时从源节点复制…交互层透明"）改写——childGraphId 现在仅属知识节点（抽象节点持有子图）。
  - `ReferenceNodeData` 的 `@remarks`（原"label / childGraphId 在创建时从源节点复制"）改写——仅复制 `label`，childGraphId 不再复制（引用节点通过 sourceGraphId/sourceNodeId 解引用源节点获取层级）。
- `DeriveAbstractionLevel` 契约签名：`node: NodeBase` → `node: NodeData`（顶层可传引用节点，derive 内部解引用）。

### 1.2 derive.ts 解引用逻辑

- `deriveNodeForm`：**零改动**（签名已收窄 KnowledgeNodeData；实现 `node.childGraphId !== undefined` 成立）。
- `deriveAbstractionLevel`：入口增加引用节点分支——`node.role === 'reference'` 时：`lookupGraph(node.sourceGraphId)` 取图 → `nodes.find(n => n.id === node.sourceNodeId)` 取源节点 → 以源节点递归推导；源节点不可达返回 0（防御，链中断语义与现状一致）。
- `deriveLevel`：参数类型改为 `KnowledgeNodeData`；递归遍历子图节点时仅对 `role === 'knowledge'` 的节点递归，引用节点跳过（贡献 0）——**防止沟通节点解引用成环**（沟通节点指向父图，若解引用会回到当前子图）。
- 环检测（onPath）保留。

### 1.3 前端收窄

- `frontend/src/feature-tools/default_tool.ts`（约 113 行）：`else if (node.childGraphId)` → `else if (node.role === 'knowledge' && node.childGraphId)`（TS 收窄；行为不变——引用节点双击仍走优先级 1 sourceGraphId）。
- `frontend/src/cytoscape/mapper-utils/class_mapper.ts`：确认 `deriveNodeForm(node)` 在 `node.role === 'knowledge'` 分支内（TS 自动收窄），**零改动**；若编译报错则补窄化。
