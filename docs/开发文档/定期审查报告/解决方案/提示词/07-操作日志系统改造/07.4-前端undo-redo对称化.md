# 07.4 前端 undo/redo 对称化 — 提示词

## 当前状态

前端回溯链路仍是**三段式手工编排**，与 07 目标（日志自包含、undo/redo 对称、纯内存执行）不符：

- `graph_store.ts` 的 `applyEntry(entryIndex, direction)`（~140 行）按 direction 分发两套逻辑：
  - `reverse`（undo）三段式：① `revertDeleteGraph`（**从持久化 loadGraph 恢复**）→ ② 图内逆元执行（跳过 added 图的 item）→ ③ `revertAddGraph`（注销）
  - `forward`（redo）：正向序列组装（registry 缺失 → 批内 add_graph 兜底）
- `graph_signals.ts`（70 行）：`revertAddGraph` / `revertDeleteGraph`——**图级 undo 依赖持久化**（revertDeleteGraph 从 localStorage loadGraph 完整恢复）
- 日志组装（`commitBatchToGraphs`）：`reversalBatch` **过滤图级逆元**（`isGraphLevelReversal`）+ `graphSignals` 摘要存入 entry；`entry.timestamp` 用 `new Date().toISOString()`（与 `executedAt` 是**两个不同时刻**，违反 07.1 批级唯一时间裁决）
- GE `apply_batches.ts`：`ApplyBatchesResult` 返回 `graphSignals` 字段（内部累积 added/deleted）
- 持久化：`delete_graph` 是**软删**（只注销注册表，localStorage 保留）——`revertDeleteGraph` 与 `findParentGraph` / `goToNearestAvailableGraph` 的父链回溯依赖这份残留

**前置条件已就绪（07.1/07.2/07.3）**：`executedAt` 参数化（批级唯一时间、正逆共用 entry.timestamp 语义）；日志命名 `OperationLogTree/CommitLog/BatchLog`；图级逆元空图 `add_graph ↔ delete_graph` 互逆（`createGraphReversal`，07.3 已验证 delete_abstract_node 的图级批完整可撤销）；`executeGraphOperation` 用 executedAt 补写图级时间戳。

## 目标

- undo/redo **对称化**：走同一条 `applyBatches` 路径，`direction` 语义与三段式手工编排消失
- `graphSignals` **全链移除**：GE 返回字段、`CommitLog` 字段、前端日志组装、`isGraphLevelReversal`、`graph_signals.ts` 全部删除
- 图级 undo **不依赖持久化**：逆元序列自包含（空图 add_graph 重建注册 + 图内内容恢复），纯内存执行
- **持久化策略 A（用户已裁决）**：`delete_graph` 正向执行时**真删持久化**；undo 逆元重建的图自动写回持久化
- `entry.timestamp` 与 `executedAt` **统一为同一值**（批级唯一时间）

## 架构变更

```
旧（现状）：
commitBatchToGraphs 正向 → reversalBatch 过滤图级逆元 + graphSignals 存 entry + timestamp=独立 new Date()
undo  = applyEntry(reverse) 三段式：① revertDeleteGraph(持久化 loadGraph 恢复) → ② 图内逆元(跳过 added 图)
                               → ③ revertAddGraph(注销)          ← graph_signals.ts 依赖持久化
redo  = applyEntry(forward) 正向序列组装(add_graph 兜底)
applyBatches 返回 graphSignals（GE 累积）        delete_graph 软删（localStorage 保留残留）

新（本子步骤）：
commitBatchToGraphs 正向 → reversalBatch 全量入日志(图内+图级) + entry.timestamp = executedAt
undo  = applyUndoEntry：组装 reversalBatch 完整序列(含图级逆元) → applyBatches(executedAt=entry.timestamp)
redo  = applyRedoEntry：组装 batch 正向序列 → applyBatches(executedAt=entry.timestamp)
applyBatches 无 graphSignals                    graph_signals.ts 删除
持久化：注册表有→saveGraph；无(delete_graph 注销)→deleteGraph(真删)；undo 重建图自然写回
```

### 4.4 applyEntry 对称化（删除 applyEntry，拆两函数）

- **删除** `applyEntry(entryIndex, direction)`（L391-530）及"统一对称的撤销模型/三段式"长 JSDoc
- 新增私有 `applyUndoEntry(entryIndex: number): boolean`：
  - 组装 `entry.reversalBatch`（完整逆元序列，含图级逆元）→ 经共享组装辅助 → `commitBatchToGraphs(batch, { recordLog: false, skipValidate: true, executedAt: entry.timestamp })`
  - 成功 → `cursor = entry.parentIndex`；失败 → 防御报告 `reportReversalApplyFailure(entryIndex, 'undo')`，返回 false
- 新增私有 `applyRedoEntry(entryIndex: number): boolean`：
  - 组装 `entry.batch`（正向序列）→ 经共享组装辅助 → `commitBatchToGraphs(batch, { recordLog: false, skipValidate: true, executedAt: entry.timestamp })`
  - 成功 → `cursor = entryIndex`；失败 → 防御报告，返回 false
- **共享组装辅助** `buildBatchesFromLogItems(items: BatchLog[], registry: GraphRegistry): OperationBatch[]`：
  - 从现状 redo 组装逻辑（L437-470）提炼：对每个 BatchLog，图级操作（`isGraphLevelOperation`）与图内操作（`isInGraphOperation`）拆分为独立批（applyBatches 判别联合要求）；inGraph 批从 registry 解析 graph 对象，缺失时用批内 `add_graph.graph` 兜底（跨 item 查找，现状逻辑），仍缺 → `reportRegistryResolveFailure` 并跳过
  - undo 传 `entry.reversalBatch`，redo 传 `entry.batch`——**同一辅助，两方向复用**
- `undo()` / `redo()` 改为调用 `applyUndoEntry` / `applyRedoEntry`（redoStack / `goToNearestAvailableGraph` 逻辑保留，见 4.8）
- `skipValidate: true` 保留传参（**必要机制**：批内 `add_edge` 依赖同批 `add_node` 重建端点，validate-all-first 基于输入图校验必然误报 `EDGE_*_NOT_FOUND`——010.1 缺陷 #1 修复的机制；非"降级为防御"）

### 4.8 goToNearestAvailableGraph 改造（方案 A 连带）

- 签名改为接收可选参数 `goToNearestAvailableGraph(orphanedParentHint?: GraphId)`：
  - 视图图仍在 registry → 直接返回（现状逻辑）

- `undo()` / `redo()` 调用时提取 hint：从撤销的 entry 中查找 `add_graph` 操作（`entry.batch` 内 `op.type === 'add_graph'` 且 `op.graph.id === 被注销视图图 id`）→ 取其 `graph.parentGraphId` 传入（undo 建图场景视图图被注销的精确恢复；无法提取则 undefined → root 兜底）
