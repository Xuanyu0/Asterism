# 02.2-graph_store 单例化改造 — 提示词

## 当前状态

前端 `graph_store.ts` 是 Pinia store（`defineStore`），用 `ref` 定义 7 个状态字段。其中多个是"死 ref"（无 UI 响应式消费）：

- `graphView`（shallowRef）——被 Graph.vue watch 消费 ✅ 保留
- `graphPath`（ref）——被导航面包屑消费 ✅ 保留
- `lastValidationResult`（ref）——被 canvasErrorIssues 消费 ✅ 保留
- `graphRegistry`（ref）——无 UI 消费，仅业务逻辑读取 ❌ 死 ref
- `operationLog`（ref）——无 UI 消费，仅 store 内部 + 测试 ❌ 死 ref
- `redoStack`（ref）——无 UI 消费，仅 store 内部 + 测试 ❌ 死 ref
- `lastSaveTime`（ref）——只写不读，无任何消费 ❌ 删除

Pinia 的 reactive proxy 与"纯函数引擎 + structuredClone + 引用替换"冲突，产生 toRaw/markRaw 摩擦。项目已有单例先例（adapters/ 的 useGraphOperationAdapter / useNavigationAdapter 是"模块级单例 + 懒创建 + 公开 interface"形态）。

## 目标

移除 Pinia 依赖，改造成项目已有的单例模式风格（模块级单例 + 组合式函数 + 公开 interface）。消灭死 ref（降级为普通字段 / 删除）。保持 `useGraphStore()` 调用签名与解包访问形态（90 处调用点零改动）。

## 架构变更

```
旧：
graph_store.ts = Pinia store（defineStore）
    · 7 个 ref 状态（含 4 个死 ref）
    · reactive proxy → toRaw/markRaw 摩擦
    · main.ts createPinia

新：
graph_store.ts = 模块级单例 + 组合式函数 + 公开 interface
    · 3 个响应式状态（graphView/graphPath/lastValidationResult，shallowReactive）
    · 3 个普通字段（registry/operationLog/redoStack，raw 无代理）
    · lastSaveTime 删除
    · useGraphStore() 返回 interface（保持调用形态）
    · resetGraphStoreForTests() 测试隔离
    · main.ts 移除 createPinia
```

## 具体子任务

### 2.1. 死 ref 审计与降级

- 保留响应式：`graphView` / `graphPath` / `lastValidationResult`（有 UI 消费）
- 降级为普通字段：`graphRegistry` / `operationLog` / `redoStack`（无 UI 消费，改普通字段，raw 无代理）
- 删除：`lastSaveTime`（含写入点 graph_store.ts:402）
- 降级后 `markRaw` / `toRaw` 摩擦消失（operationLog 不再需要 markRaw，registry 不再需要 toRaw）

### 2.2. 移除 Pinia，单例化

- 移除 Pinia 依赖（package.json 移除 pinia、main.ts 移除 createPinia）
- 模块级单例 + 组合式函数 `useGraphStore()` 返回公开 interface
- 用 `shallowReactive` 单例保持 `store.graphView` 无 `.value` 访问形态（90 处调用点零改动）
- 公开 interface：只读 state + 方法入口
- 测试隔离：`resetGraphStoreForTests()` 替代 `setActivePinia(createPinia())`（29 处测试文件）

### 2.3. OOP 化（语义命名 + 职责分组）

- 函数语义化命名（需用户确认，见不确定事项）：`loadGraphToView` → `openGraph`、`initRegistry` + 哨兵 + 兜底 → `restoreSession` 等
- 启动引导舞收口（Graph.vue onMounted 四步序列 → 单方法）
- 状态分类分组（视图态 / 多图缓存 / 撤销日志 / 校验瞬态）
