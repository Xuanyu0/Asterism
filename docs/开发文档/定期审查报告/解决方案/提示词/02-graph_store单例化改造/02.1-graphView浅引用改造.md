# 02.1-graphView 浅引用改造 — 提示词

## 当前状态

前端 `graph_store.ts` 中 `graphView` 是 `ref<GraphData | null>`（graph_store.ts:90），`.value` 是深代理的 GraphData。深代理导致：

- `default_tool.ts:151` 被迫 `toRaw(original)` 解包（引擎 reversal 逆元 structuredClone 无法克隆 proxy）
- `preview_engine.ts:254` 被迫 `JSON.parse(JSON.stringify())` 克隆（同上）

本次改造：graphView 改 `shallowRef`，`.value` 保持 raw，消除这两个 workaround。

## 目标

完成后，`graphView.value` 是 raw GraphData（永不进深代理），引擎可直接 structuredClone。`default_tool.ts` 的 toRaw 与 `preview_engine.ts` 的 JSON 序列化克隆消除。Graph.vue 渲染同步照常。

## 架构变更

```
旧：
graph_store.ts: graphView = ref<GraphData | null>（.value 深代理）
    ↓ 引擎 structuredClone 无法克隆 proxy
    ↓ default_tool.ts:151 toRaw 解包
    ↓ preview_engine.ts:254 JSON 序列化克隆

新：
graph_store.ts: graphView = shallowRef<GraphData | null>（.value 保持 raw）
    ↓ 引擎可直接 structuredClone
    ↓ default_tool.ts 消除 toRaw
    ↓ preview_engine.ts cloneGraph 改 structuredClone
```

## 具体子任务

### 1.1. graphView → shallowRef

- `graph_store.ts:90`：`const graphView = ref<GraphData | null>(null)` → `shallowRef<GraphData | null>(null)`
- import 从 `ref` 改为 `shallowRef`（注意：graph_store.ts 还用了 `ref` 定义其他状态，保留 `ref` import，新增 `shallowRef`）
- 所有 `graphView.value` 读写不变（引用替换语义一致）

### 1.2. 消费方 workaround 消除

- `default_tool.ts:151`：消除 `toRaw(original)`，直接使用 `original`（数据已是 raw）
- `preview_engine.ts:254`：`cloneGraph` 从 `JSON.parse(JSON.stringify(graph))` 改 `structuredClone(graph)`，更新注释（不再需要 JSON 序列化绕行 proxy）

### 1.3. 渲染链路验证

- Graph.vue 代码不改（watch 只依赖引用层面，与 shallowRef 完全兼容）
- 前端测试全绿
