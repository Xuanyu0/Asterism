## 3. 问题二：数据流是否真实可信

**主干判定：真实。** 用户 DOM → Cy 原始事件 → 语义事件 → mediator → 工具 → 用例 → store → GE → 新 registry → 引用替换 → `watch(GraphView)` → `syncFromGraphData` 这条链与代码一致；`§` 回环方向（GE 产物回到 Runtime 做引用替换）与 `graph_store.ts:238` 相符。以下 4 条不真实或不完整：

| ID | 位置 | 问题 | 严重度 | 置信度 |
| --- | --- | --- | --- | --- |
| A-3 / B-6 | CLAUDE.md:274-276 | **归因错误**：`preview graph ↓ renderer.syncFromGraphData` 被画在"组件与装配层"之下，真实调用者是**工具交互逻辑层**（`add_node.ts:222`、`add_edge.ts:198`、`move_node.ts:200` 直调 `useRenderer().syncFromGraphData(previewGraph)`）。图中因此缺一条真实存在的 **skip-level 边 `feature-tools → cytoscape`**（另含 `components/GraphFloatingWindow.vue:127,324` 直取 `renderer.attachPopper`） | 高 | 高 |
| A-4 | CLAUDE.md:199-200 | **环节缺失**：`语义事件 ↓ mediator 转发到活跃工具` 缺中间一跳"`Graph.vue` 装配 handler 对象"。`cy_interaction.ts` 只产出回调名，绑定与**唯一分发门控**（`activeToolId !== 'default'` 才允许双跳导航、调用前 `mediator.deactivate()`）都在 `Graph.vue:136-163`；跳过它会把"事件直连工具层"读成架构事实 | 中 | 高 |
| A-5 | CLAUDE.md:219-221 | **启动路径缺失且图给的是另一版本**：`Graph.vue:127-131` 的 `onMounted` 走 `useLifecycle().registerAllGraphs()` → `ensureWorkspaceRoot()` → **直接** `graphStore.loadGraphToView(rootId)`（绕过用例层 `goToGraph`）；`main.ts:7` 另有无条件 `@/dev/bootstrap` 导入 | 中 | 高 |
| B-6 | CLAUDE.md:274-276 | 同上一条的兄弟事实：工具在取消/确认时用**真实图**直接重同步渲染（`add_node.ts:108,185`、`add_edge.ts:64,112`、`move_node.ts:228`），图中只画了 preview 与组件两条来源 | 中 | 高 |

### 6.4 让子图可用的最小补规则清单（按优先级）

1. **一图一块**：规定含图的 md 每份只允许一个 `text` 图块；或把两脚本改为扫描全部 `text` 块（改一个定位函数即可）。
2. **跨图引用**：定义 `§` 的跨文档形态（如 `§<文档>#<层名>`），或规定"外部层 = 仅写 `≝` 的黑盒层且必须标注 `← 外部层`，禁止重定义其 `s.t.`"。成本：一段规则文字 +（可选）`§` 目标存在性校验。
3. **契约继承**：父层 `s.t.` 对子图全域继承；子图只写增量；冲突以父图为准、只许窄化不许放宽。成本：一条规则 + 明确的仲裁方向。
4. **层级**：正式声明"条目深度 ≤ 1（12 格），子结构只能内联 `= { … }`"；若要两层，先扩脚本支持 16/20 并定义对应对齐列。
5. **`=` 判据**：定义"实现集合"的成员边界（建议明确排除 `*.test.ts`、`AGENTS.md`），并规定"条目集 = 实现集"才写 `=`；同时区分三种 `=`（层↔基目录的集合关系 / 条目级成员枚举 / `s.t.` 内等值）。
6. **依赖边界**：把 CLAUDE.md:287 的单向依赖规则提升为可在图中书写的一行契约（每层允许的 import 目标集），子图引用外部层时复用。
7. **`←` 与 `↓` 消歧**：定义 `←` 的类别与解析规则；定义裸 `↓`（层出入标记）与 `↓ 动作`（管道步骤）的区别；规定层名与流块的分隔要求。
8. **脚本修复（非设计决策）**：多基目录公共前缀为空时不得生成绝对路径候选（`check_architecture_paths.py:102-105`）；把 check 脚本补进 CLAUDE.md 的命令清单（当前 `CLAUDE.md:19-38` 只列了 format 脚本）。
