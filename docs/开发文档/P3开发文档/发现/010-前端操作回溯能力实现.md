## 执行发现（@fixer 010.2 测试期）

### 缺陷：撤销「删除带关联边的节点」失败（D1，已修复）

- 根因：① 逆元组装 `collectedReversals.reverse()` 整体逆序，翻乱 `createReversalForDeleteNode` 的 `[add_node, add_edge]` 内部执行序；② 更根本——`applyBatch` validate-all-first 基于输入图静态校验，恢复型逆元批（add*edge 端点依赖批内 add_node 恢复的节点）必然 `EDGE*\*\_NOT_FOUND`
- 处理（用户批准破例改引擎）：引擎 `pipeline.ts` 加 `BatchOptions.skipValidate`（Phase 1 条件跳过，Phase 3 全局规则保留）；前端逆元组装改「操作级逆序」（每 op 逆元数组保持内部序，op 间逆序）；applyEntry reverse/forward 传 `skipValidate: true`
- 状态：✅ 已确认（undo_redo.test.ts「缺陷修复回归」describe 保护）

### 缺陷：多级 undo 抛 DataCloneError（D2，已修复）

- 根因：operationLog 为 reactive ref，读出操作被深层 proxy 包装；引擎 execute 浅展开 `{...op.node}` 把嵌套 position proxy 烘焙进图数据；后续逆元 structuredClone 崩溃（真实场景所有节点带 position，必然触发）
- 处理：entry 组装后整体 `markRaw` 再 push 进 entries（Vue 尊重 markRaw，读出不包装）
- 状态：✅ 已确认

### 信息：add_graph 批 undo 持久化被空壳覆盖（oracle 发现 #1，已修复）

- 位置：applyEntry reverse ② + commitBatchToGraphs 第四阶段 saveGraph
- 现象：undo ② 对 added 图执行图内逆元后，第四阶段把空壳中间态写回持久化，覆盖正向批填充版——undo 后刷新/新操作（redo 失效）子图内容永久丢失
- 处理：applyEntry ② 跳过 `graphSignals.added` 中图的 reversal item（③ 注销后其图内逆元无意义；④ 不再覆盖该图持久化）
- 状态：✅ 已确认（测试新增断言：undo 后 loadGraph 子图节点完整）

## 用户检查阶段发现（move 预览污染，已修复）

### 缺陷：move 预览污染 GraphData → move 的 undo/redo 失效（严重，已修复）

- **现象**：move 工具拖动预览后 `graphStore.graphView` 中被移动节点 position 被**原地修改**为预览目标值 → 放置时 move 变"原地移动"（目标 = 当前位置）→ 逆元捕获目标位置 → **Ctrl+Z undo 无效**（无任何提示）
- **根因**（fixer 实证，headless cytoscape 隔离复现）：
    1. `cy_element_mapper.ts` `position: node.position` 将 graphData 节点 position **按引用**传给 Cytoscape；Cytoscape Element 构造器**按引用存储**（element.mjs `_private.position = params.position`）
    2. 预览 sync：`cy.json` 对已存在元素走 `ele.position(预览位置)` → **原地写回共享的 `_private.position`**（即 graphView 的 Vue reactive proxy）→ **写穿回 graphStore.graphView**
    3. 逆元构造时 graphBeforeOp 已是污染值 → undo 无效
- **修复**：`cy_element_mapper.ts` `position` 改值拷贝 `{ x, y }`（Cytoscape 持有自属副本，写回只发生在副本上；"GraphData 唯一事实源"在映射层强制执行）+ 4 个回归测试（`cy_element_mapper.test.ts`）
- **影响面**：潜伏性架构隐患——任何"cy 元素已存在 + 再次 sync 不同位置"的路径都会写穿（add_node 等后续工具同样受影响），mapper 统一封堵；`cy.add` 路径（新增元素）同样按引用存储，值拷贝后两条路径均安全
- **调试方法记录**（log 大法实证）：污染检测分三段（previewMoveNode 后 / sync 后）、clone 深拷贝验证（JSON 深拷贝正常）、toRaw 解包共享验证（排除引用共享）、最终定位到 Cytoscape 引用存储 + 原地写回
- 状态：✅ 已确认（用户验证 move → undo 恢复原位）

### 信息：Cytoscape 引用存储 position 的架构教训

- Cytoscape Element 构造按引用存 position、cy.json 更新原地写回——渲染层（只读映射）若不拷贝，会反向写穿 GraphData。**架构约束"渲染层禁止持有/修改 GraphData"必须由映射层值拷贝兜底**（不能依赖下游库的拷贝行为）
- 状态：✅ 已确认
