# 09.1-逆元重构与单测 — 提示词

## 当前状态

- `packages/graph-engine/src/core/reversal.ts`：
  - `createReversalForDeleteNode` 只捕获被删节点 + 直接关联边（未捕获 executeDeleteNode 级联删除的同图引用节点及其边）
  - `createReversalForExpandDependency` 查到了原折叠条目却丢弃 `foldedNodeIds`，逆元只返回 `collapse_dependency(targetNodeId)`（executeCollapseDependency 会重算成员）
  - `createReversalForAddGraph` / `createReversalForDeleteGraph` 存在（图级逆元）
  - 各函数目标缺失时静默 `return []`（undo 变 no-op）
- `packages/graph-engine/src/types/atomic_operations.ts`：`CollapseDependencyOperation` 仅含 `targetNodeId`
- `packages/graph-engine/src/core/execute.ts`：`executeCollapseDependency` 用 `collectDependencyNodeIds` 重算折叠成员
- `packages/graph-engine/tests/core/reversal.test.ts`：覆盖 add_node / add_edge / delete_node / delete_edge / update_node / update_edge / move_node / add_graph 八块，无 delete_graph / collapse / expand

## 目标

逆元与 execute 实际副作用面镜像；expand 逆元携带原折叠条目；图级逆元函数删除；静默失败改为显式错误。设计依据 `docs/临时文档/GE端逆元问题报告.md` §2/§8 与 `docs/开发文档/P3开发文档/步骤/09-GE端操作回溯重构.md` §1/§4。

## 具体子任务

### 1.1 delete_node 捕获面扩展

**子目标**：

- `createReversalForDeleteNode(graph, operation)` 捕获面扩展为 execute 删除面镜像：
  - 被删节点（完整快照）
  - 被删节点直接关联边
  - **级联删除的同图引用节点**（`graph.nodes` 中 `role === 'reference' && sourceNodeId === 被删节点id && sourceGraphId === graph.id`）
  - 上述级联引用节点的关联边
- 恢复顺序：先节点后边（边依赖端点存在）；级联引用节点在其边之前恢复。
- 折叠状态**不恢复**（决策 B，已知限制——不捕获 cognitiveState 变动）。

### 1.2 expand 逆元携带原折叠条目

**子目标**：

- `createReversalForExpandDependency(graph, operation)`：查原折叠条目（`graph.cognitiveState.foldedDependencies` 中 `targetNodeId` 匹配项），逆元返回 `collapse_dependency(targetNodeId, foldedNodeIds)`——携带原条目的 `foldedNodeIds`；原条目缺失 → 按 1.4 显式错误处理。
- `CollapseDependencyOperation` 增加可选字段 `foldedNodeIds?: NodeId[]`（atomic_operations.ts）。
- `executeCollapseDependency`：**有 `foldedNodeIds` 字段时直接用字段值**作为折叠成员（不重算）；无字段时保持现状（`collectDependencyNodeIds` 重算 + 空成员静默 no-op）。有字段但字段为空数组时按"空成员"语义处理（与无字段空结果一致：不写条目）。

### 1.3 删除图级逆元构造

**子目标**：

- 删除 `createReversalForAddGraph` / `createReversalForDeleteGraph` 函数及 `createReversal` switch 中对应的 case 分支。
- `createReversal` 对 `add_graph` / `delete_graph` 落到 default 返回 `[]`（前端回调对图级操作不调用 createReversal，返回空不影响）。
- 清理不再使用的 import（`AddGraphOperation` / `DeleteGraphOperation` 等）。

### 1.4 静默失败显式化

**子目标**：

- 各逆元函数（delete_node / delete_edge / update_node / update_edge / move_node（含 `!current.position` 双条件）/ expand）在目标缺失时改为**抛异常**（显式错误信号），不再静默 `return []`。
- 异常类型自定（Error 子类或普通 Error），message 含操作类型与缺失目标 id。
- 正常流程（操作执行前构造，validate 已保证目标存在）不触发；前端回调捕获后阻断整批（前端接线属 010，本步骤只保证引擎侧显式报错）。

### 4.1 测试更新

**子目标**：

- `reversal.test.ts`：
  - **删除** `createReversal add_graph` 测试块（图级逆元已删）
  - **更新** delete_node 测试：断言逆元包含被删节点 + 直接边 + 级联引用节点 + 其边（构造含引用节点指向被删节点的图）
  - **更新** expand 测试：断言逆元携带原 `foldedNodeIds`；`executeCollapseDependency` 用字段恢复后折叠条目与原一致
  - **新增** collapse 显式折叠成员测试（带 `foldedNodeIds` 时 execute 用字段值，不带时重算）
  - **新增** 静默失败测试（目标缺失 → 抛异常）
- 既有 execute / pipeline 测试不破坏（executeCollapseDependency 无字段路径保持原行为）。
