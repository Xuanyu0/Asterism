# 09.2-applyBatch 回调与日志类型升级 — 提示词

## 当前状态

- `packages/graph-engine/src/compose/pipeline.ts`：`applyBatch(graph, ops, options?)` 的 dry-run 循环（`for (const op of ops) { resultGraph = executeOperation(resultGraph, op) }`）内部中间态不可观测；`BatchOptions` 无逐操作挂点。
- `packages/graph-engine/src/types/operation_log.ts`：`OperationLogEntry` 为原子粒度（`operation: GraphOperation` 单操作）；无按图分组结构、无图级元数据字段。
- `packages/graph-engine/src/index.ts`：导出 `OperationLogEntry` / `OperationLog` / `State` 类型。

## 目标

applyBatch 增加逐操作可选回调（暴露原子操作级中间态，引擎保持无感知）；操作日志类型升级为"批粒度 + 按图分组 + 图级元数据"，支撑"一次 commitBatchToGraphs = 一条 entry = 一次回溯单元"（前端 010 使用）。

## 具体子任务

### 2.1 onBeforeEachOperation 可选回调

**子目标**：

- `BatchOptions` 增加可选 `onBeforeEachOperation?: (op: GraphOperation, graphBeforeOp: GraphData) => void`。
- dry-run 循环（executeOperation 之前）调用该回调，入参为该操作与其执行前的图状态（中间态）。
- 语义：回调不改变执行结果，仅暴露中间态；未传时不调用（零行为变化）。

### 3.1 ItemOperations 结构与 entry 升级

**子目标**：

- 新增 `interface ItemOperations { graphId: GraphId; operations: GraphOperation[] }`（按图分组，item 的日志形态）。
- `OperationLogEntry` 升级：
  - `operation: ItemOperations[]`（一批正向操作，按图分组）
  - `reversalOperations: ItemOperations[]`（一批图内逆元，undo 执行顺序——item 间逆序 + item 内逆序）
  - `graphSignals: { added: GraphId[]; deleted: GraphId[] }`（图级元数据）
  - `parentIndex: number` / `timestamp: string` 不变
- `OperationLog` / `State` 结构不变（State MVP 后置，仅保留定义）。
- `index.ts` 相应导出 `ItemOperations` 类型。

## 变更边界

**禁止修改**：

- `applyBatch` 的执行语义（validate-all-first / dry-run / 全局规则 / 事务性）
- `execute.ts` / `reversal.ts`（逆元重构属 09.1）
- `frontend/` 任何文件（回调消费与 entry 组装属 010）
- 现有测试断言的执行结果（回调为可选增量，不改变 applyBatch 返回值与行为）

## 验收标准
