# 08.5.1 引擎 label 规则（EMPTY_LABEL 迁入）— 提示词

## 当前状态

`packages/graph-engine/src/core/validate.ts` 的 `validateAddNode`（L46）现有校验：NODE_ID_DUPLICATED / NODE_COUNT_HARD_LIMIT_EXCEEDED / NODE_COLLISION——**无 label 校验**。空 label 的拒绝目前只在前端 `feature-tools/toolbar/add_node.ts` 的预校验（构造 EMPTY_LABEL 直写 store，属越界），图规则未归引擎（Q3 已确认：空 label 应为引擎 `add_node` 图规则）。

## 目标

"label 非空"成为引擎 `add_node` 图规则（trim 后非空），`validateAddNode` 产出 EMPTY_LABEL error；前端预校验在 08.5.2 删除（本任务只做引擎侧）。

## 具体子任务

### 5.1 校验规则

`core/validate.ts` 的 `validateAddNode` 增加"label 非空"校验：

- 判定：`operation.node.label` trim 后为空 → 拒绝
- issue：`severity: 'error'`、`code: 'EMPTY_LABEL'`、`message` 与前端原文案一致（"节点标签不能为空。"）、`targetType: 'node'`、`targetId: operation.node.id`
- 注意 `NodeData.label` 的实际类型（string 必填或可选）——若可为 undefined 需一并处理空值；以实际类型为准
- 其余现有校验（NODE_ID_DUPLICATED 等）与 createResult 结构不动

### 5.1 测试

引擎 `validate.ts` 对应测试新增 EMPTY_LABEL 分支：

- 空 label（`''`）→ error EMPTY_LABEL
- 纯空白 label（`'   '`）→ error EMPTY_LABEL（trim 语义）
- 正常 label → 无 EMPTY_LABEL（其余校验行为不变）
