# 08.2 loadGraphToView 与静默路径治理 — 提示词

## 当前状态

`graph_store.ts` 的 `loadGraphToView` 把非规则校验问题写入 `lastValidationResult`（越界）：`LOAD_FAILED`（I/O 失败借用规则通道）、`ANCESTOR_CHAIN_BROKEN`（`valid: true` 警告写进通道但 Graph.vue 只显 error，形成"写了没人读"的死通道）。`buildGraphPath` 的环检测 / 父缺失、`initRegistry` 的加载失败均静默无痕。项目当前 0 条 console 日志。

已确立的通道语义（08 步骤 1，执行本任务前已确认）：

- **validation 通道（lastValidationResult）= 图规则校验专用**（引擎 applyBatch / compose 产出）
- **开发者通道 = 图规则校验以外的一切**（数据损坏、链断裂、环、I/O 失败）——当前落地为 `console.warn`，用户默认不可见
- **missing（图不存在）= 正常状态，静默**；**corrupted（图损坏）= 系统异常，入开发者通道**

前置：08.1 已交付 `loadGraph` 判别联合（`LoadGraphResult`），本任务在其基础上进行。

## 目标

`loadGraphToView` 退出对 validation 通道的借用；`buildGraphPath` / `initRegistry` 的防御路径补开发者通道记录。完成后 `lastValidationResult` 的写入来源收敛为 `commitBatchToGraphs` 一处（前端零直写规则校验以外的内容）。

## 具体子任务

### 3.1 开发者通道报告辅助函数

`graph_store.ts` 文件末尾（私有辅助区）按**异常语义类别**拆分报告辅助函数，每个负责"记录一类系统异常"（检测在调用方，辅助只做记录）：

- corrupted 报告：入参 graphId，`console.warn` 携带结构化信息（code + 描述 + targetId）
- 链断裂报告：入参 graphId / 断裂处 terminalId / 缺失父图 id，`console.warn` 携带上述信息
- 环检测报告：入参导致回退的父 id，`console.warn` 携带信息

约定：所有报告带统一前缀（如 `[data-integrity]`）便于过滤；输出含 machine code（如 `CORRUPTED_GRAPH` / `ANCESTOR_CHAIN_BROKEN` / `CYCLE_DETECTED`）与人类可读描述。具体命名与格式由实现决定，但 code 语义与信息完整度按上述约定。

### 3.2 loadGraphToView 重构

基于 08.1 的判别联合：

- **LOAD_FAILED 拆分**：
  - missing → 静默返回 `false`，不写任何状态（防御态：正常路径下不可达，UI 兜底逻辑不变）
  - corrupted → 调 corrupted 报告辅助（console.warn）+ 返回 `false`，**不写 lastValidationResult**
  - 删除 `LOAD_FAILED` 的 `lastValidationResult` 写入分支
- **ANCESTOR_CHAIN_BROKEN 迁移**：从 `lastValidationResult` 移除，改调链断裂报告辅助（console.warn）；删除 `valid: true` warning 写入分支
- 其余正常路径（ensureDefaultCognitiveState / registerGraph / buildGraphPath / saveLastActiveRootId / clearValidationResult）行为不变
- 更新 `loadGraphToView` JSDoc：错误出口说明改为"missing 静默 / corrupted 与链断裂走开发者通道"

### 3.3 静默路径补记录

- `buildGraphPath`：环检测 break 处、父缺失 break 处补环检测报告 / 链断裂报告（保留现有防御行为，只加记录）
- `initRegistry`：corrupted 时调 corrupted 报告辅助（区分"首次使用"与"数据损坏"）；missing 保持静默（现状）

### 3.4 单测更新（行为变更断言）

- 更新 `graph_store` 相关测试：`loadGraphToView` 对 corrupted 不再写 `lastValidationResult`、missing 静默返回 false 的断言
- `ANCESTOR_CHAIN_BROKEN` 不再写 `lastValidationResult` 的断言
- 确认规则校验路径（commitBatchToGraphs / 工具层）的 `lastValidationResult` 行为不变（useGraphOperationAdapter 测试不回归）
