# 011.3.拼接式UI布局 — 提示词

## 当前状态

- `frontend/src/components/GraphNodeWindow.vue`：浮空窗已锚定到目标右侧（`placement: 'right'` 契约，目标恒在窗左侧）。模板为单一 formModel 驱动结构：
  - 顶部 header 行（标题 `{{ formModel.title }}` + 右上角 ✕ 圆钮）
  - 标签行（下划线式 input + placeholder"请输入标签..."）
  - 摘要区（横线纸 textarea：`summary-input` scoped 类 + maxlength 80 + 固定 3 行 + resize-none）
  - 底部整行 Confirm 按钮（`btn-primary`）
  - 主容器样式：`bg-stone-50/80 backdrop-blur` + `border-2` + 圆角（有阴影样式残留需清理）
- 设计文档 `docs/设计/08-拼接式UI.md` 定义目标形态（见目标节）。
- `formModel`（computed 视图模型）提供：`title` / `label` / `summary` / `showSummary` / `onLabelInput` / `onSummaryInput` / `onConfirm` / `onClose`。**结构不可变**。

## 目标

依据 `docs/设计/08-拼接式UI.md`，把 GraphNodeWindow 改造为**拼接式布局**，让浮空窗与被操作对象产生明确的视觉指向与功能分区：

- **功能面板**：只承载表单（标签 + 摘要）。去掉顶部 header 行与底部整行 Confirm 按钮。
- **标题卡片**：吸附在面板左侧，垂直对齐面板水平中轴线；卡片左边框中部有**小三角箭头指向左侧的被操作对象**；内容显示 `formModel.title`。
- **两个圆形外框按钮**：吸附在面板右侧，同一尺寸；**✕ 取消**在面板水平中轴线偏上、**浅红底**；**✓ 确认**在面板水平中轴线偏下、**浅绿底**。
- 整体**无阴影**；面板、卡片、按钮三者**边界线清晰**；元件间留**微小空隙**但视觉上组合为一体（同一容器内组合，无需任何吸附/定位逻辑代码）。

```
         │  ┌─────────┐          │ ✕  │ ← 浅红圆钮，右缘凸出，中轴线偏上
         │◀─┤ 标题卡片  │◄─三角─┐  └────┘
         └──┴─────────┘        │  ┌────┐

              │  标签: [_____]     │ └────┘
              │  摘要: ──────      │
              │       ──────      │
              └───────────────────┘
```

## 具体子任务

### 3.1 布局结构改造

- 主容器：移除 header 行（标题 + ✕）与底部 Confirm 按钮行，只保留标签行与摘要区；**移除全部阴影**，保持/强化清晰边界线。
- 标题卡：独立小卡片吸附面板左缘、垂直对齐面板水平中轴线；卡片左侧中部一个三角箭头朝左（指向被操作对象）；内容 = `{{ formModel.title }}`（沿用现有标题文案，不新增文案）。
- 操作双钮：吸附面板右缘，同尺寸圆形外框；✕（XMarkIcon）浅红底、✓（CheckIcon）浅绿底；✕ 点击 → `formModel.onClose`，✓ 点击 → `formModel.onConfirm`。
- 三元件在同一容器内组合，留微小空隙，不需要额外吸附逻辑。

### 3.2 行为保持

- `formModel` 结构、分派逻辑、数据流**一律不动**。
- 锚定（watch + attachPopper + registerWindowRoot）**不动**。
- 摘要横线纸（`.summary-input` scoped 类、maxlength 80、resize-none、3 行固定高度）**保持原样**；标签下划线式**保持原样**。
- import 增加 `CheckIcon`（`@heroicons/vue/24/outline`，与 XMarkIcon 同源）。

### 3.3 测试与验证

- 运行 `pnpm --filter frontend test`：现有 186 用例全绿（纯视图结构调整，无逻辑变化）。
- type-check 通过（`pnpm --filter frontend type-check`，如项目有该脚本；无则 vue-tsc）。
- 手动冒烟点（供用户复验，非自动）：草稿/编辑两模式渲染、✕✓ 点击分派、外部点击关闭不受影响。
