# 011.1.浮空窗锚定到目标节点/边 — 提示词

## 当前状态

- `frontend/src/components/GraphNodeWindow.vue`：`.floating-window` 样式 `position: absolute; top: 20px; right: 20px`（固定画布右上角，不跟随节点）；组件是 Graph.vue 的模板子组件，**无 Teleport**；根元素经 `registerFloatingContainer` 注册给 useFloatingWindow 用于外部点击关闭判定。
- `frontend/src/cytoscape/useRenderer.ts`：Cytoscape 渲染单例；模块顶层已 `cytoscape.use(cytoscapeCanvas)`（L30）；`mount()` 创建 cy 实例；RendererAPI 已有 `trackCursor` / `syncFromGraphData` / `addNodeClass` 等。
- `frontend/src/feature-tools/composables/useFloatingWindow.ts`：浮空窗状态单例（floatingData + open/close/registerContainer + window pointerdown 外部点击关闭）。
- `frontend/src/feature-tools/default_tool.ts`：`onNodeClick` / `onEdgeClick` → `floatingWindow.open(node/edge)`（实体带 id）。
- `frontend/src/feature-tools/toolbar/add_node.ts`：`previewAddNode` 生成预览 `nodeId`；点击画布后预览节点定格在画布上（`draftNode` 创建，预览图仍在渲染）；`DraftNode` 类型**无 nodeId 字段**。
- 依赖**未安装**：`cytoscape-popper` / `@floating-ui/dom`。
- 引擎（`packages/graph-engine/`）零改动。

## 目标

- 浮空窗从"固定右上角"改为"**锚定到目标右侧**"：add-node 预览节点 / 被编辑节点 / 被编辑边（边锚定到中点），跟随目标位移与画布平移缩放实时更新。
- 渲染层提供**通用锚定 API**（cytoscape/ 内新增模块），供 GraphNodeWindow 及未来操作日志侧边栏详情浮卡（设计文档 07-操作回溯.md UX 设计）复用。
- 浮空窗 DOM 经 `<Teleport to="body">` 传送；视觉样式 `.floating-window` **完全保留**（popper 只写 left/top）。

## 架构变更

```
旧：GraphNodeWindow（Graph.vue 子组件）→ 画布容器内 absolute 定位 → 固定右上角
    useRenderer.ts 仅注册 cytoscape-canvas

新：GraphNodeWindow → <Teleport to="body">（物理挂 body，逻辑仍组件树）
    cytoscape/cy_popper.ts（新增）：popperFactory + 扩展注册 + attachElementPopper(cy, elementId, contentEl, options?)
        → 返回 { update, destroy }；事件绑定 node.on('position') + cy.on('pan zoom resize')
    useRenderer.ts：顶层注册 popper 扩展；RendererAPI 新增 attachPopper(elementId, contentEl, options?)（内部持有 cy）
    锚定目标 id：default 场景 = floatingData 实体 id（node.id / edge.id）；add-node 场景 = 预览 nodeId（DraftNode 新增字段）
```

## 具体子任务

### 1.1 依赖安装与扩展注册

- `pnpm --filter frontend add cytoscape-popper @floating-ui/dom`（加到 dependencies）。
- 新增 `frontend/src/cytoscape/cy_popper.ts`：
  - 导出 `registerPopperExtension()`：`cytoscape.use(cytoscapePopper(popperFactory))`——**v4 必须传 factory**。
  - `popperFactory(ref, content, options)`：`computePosition(ref, content, { middleware: [flip(), shift({ limiter: limitShift() })], ...options })` → 写 `content.style.left/top` → 返回 `{ update }`。middleware **必带 flip + shift({limiter: limitShift()})**（视口边缘自动翻转/平移，不截断）。
  - 导出 `attachElementPopper(cy, elementId, contentEl, options?)` → `{ update, destroy }`：
    - 目标解析：`cy.getElementById(elementId)`；节点 → 用元素包围盒中心（ele.popper 默认行为）；**边 → 用包围盒中心即中点**。
    - 返回的 `update` 调 popper 实例 update；`destroy` 解绑全部事件 + 清理 popper（floating-ui 实例 cleanup / destroy）。
  - JSDoc 注明：模块职责 = 渲染层 Cytoscape 外部库隔离边界内的 popper 锚定；API 通用（非 GraphNodeWindow 专用，供操作日志侧边栏详情浮卡复用）。

### 1.2 useRenderer 暴露锚定 API

- `frontend/src/cytoscape/useRenderer.ts`：
  - 顶层调用 `registerPopperExtension()`（与 `cytoscape.use(cytoscapeCanvas)` 并列）。
  - RendererAPI 新增 `attachPopper(elementId: string, contentEl: HTMLElement, options?: unknown): { update(): void; destroy(): void }`——内部委托 `attachElementPopper(cy, elementId, contentEl, options)`；cy 未挂载时返回 no-op（update/destroy 空实现）。
  - 不改变现有方法签名与行为。

### 1.3 GraphNodeWindow 锚定接线

- `frontend/src/components/GraphNodeWindow.vue`：
  - 两个浮空窗 div（DraftNode 窗 + 编辑窗）外包一层 `<Teleport to="body">`（或分别在两个 div 上包，视结构最简而定）——物理挂 body，逻辑组件树不变。
  - 移除 `.floating-window` 的 `position: absolute; top: 20px; right: 20px` 定位声明（popper 注入 left/top）；**其余视觉样式（背景/边框/圆角/阴影/尺寸/字体等）一律不动**。
  - 锚定接线：浮空窗打开时（draftNode 或 floatingData 非空）用根元素 ref + 目标 id 调 `renderer.attachPopper(id, rootEl)` → 持有句柄；关闭/切换目标/组件卸载时调 `destroy`（单实例，不泄漏）。
  - 锚定目标 id 解析：`draftNode` 非空 → `draftNode.nodeId`（预览节点）；否则 `floatingData` 非空 → `floatingData.id`（node.id / edge.id）。
  - 现有 `registerFloatingContainer`（外部点击关闭判定）保留，与锚定共用同一根元素。

### 1.4 锚定目标数据流（add-node 预览节点）

- `frontend/src/feature-tools/toolbar/add_node.ts`：
  - `DraftNode` 接口新增 `nodeId: string` 字段（预览节点 ID，供浮空窗锚定）。
  - `applyAddNodePreview` 返回值已含 `nodeId`——`onCanvasClick` 定格预览时把它写入 `draftNode.value.nodeId`。
  - `onConfirm` / `updateDraftNode` 等保持 nodeId 不变（构造真实 NodeData 时仍用 `generateNodeId()` 生成新 id，**不要复用预览 nodeId**）。
  - 其他文件对 DraftNode 的构造点同步补 `nodeId` 字段（若有）。
- `frontend/src/feature-tools/default_tool.ts`：无需改（`floatingWindow.open(node/edge)` 已带实体 id）。

### 2.1 单元测试

- `frontend/src/cytoscape/cy_popper.test.ts`（新增）：
  - `registerPopperExtension` 可重复调用不抛错；factory 的 middleware 含 flip / shift。
  - `attachElementPopper`：传入 mock cy（getElementById / on / popper）→ 返回 update/destroy；update 调用 popper.update；destroy 解绑事件。
  - 边锚定：mock 边元素 → ref 用包围盒中心。
- GraphNodeWindow / add_node 既有测试回归：Teleport 与新增 DraftNode.nodeId 字段后不破坏（mock 边界按需补充）。
