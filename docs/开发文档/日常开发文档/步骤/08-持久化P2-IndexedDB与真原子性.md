
两条合起来保证「**介质切换只能发生在 `medium/` 内部**」—— 将来谁在 `categories/` 里写了 `localStorage` 或 `indexedDB`，契约立刻判假。

## 4. 问题背景（为什么需要这一步）

`commit.ts` 头注释如实固化的三条 P1 边界，就是 P2 要消灭的对象：

1. 写入失败返回可判别结果，调用方不推进内存状态 —— **只保护本次会话**；
2. 已写成功的条目**不撤销** → 磁盘可能留下「既非旧状态、也非新状态」的**半写态**；
3. 下次启动直接读磁盘，会把半写态**读成基线** —— 不一致被**静默合法化**。

根因只有一个：**localStorage 无事务**（`B-3`）。P1 的裁决是**不在 P1 用回滚 / 日志 / 单键批量写去模拟事务**（用户已裁决不做）→ 真原子性必须等真正的介质事务。**这就是 P2 的全部理由。**
