## 目标（已达成）

让「一棵根图谱树」成为**引用闭合**的单元：

> 任意图 G 的节点，其 `sourceGraphId`（引用节点）与 `childGraphId`（抽象节点）必须指向**与 G 同属一棵根图谱树**的图。

同树内跨子图谱引用**继续允许**（「发散」的核心设计功能）；跨根图谱树**禁止**。

**为什么值得单独一步**：跨树引用破坏的不只是导出（那只是症状），而是「**树 = 一个自洽的编辑历史**」这条不变式 —— `graph_store.ts` 把根图定义为操作日志与 undo/redo 的边界（「根图谱 = 日志」）。一次操作横跨两棵树，其日志与撤销都会越界。

## 已定决策（摘要）

- 不变式：允许同树跨子图引用，禁止跨根图谱树。
- **硬守卫落引擎**：注册表级、**后置**；与 `DANGLING_REFERENCE`（同图引用完整性）同族同层。
- 粒度判据：**森林级 = 判定需要树外数据**（对 **树级** = 只依赖单棵树内部数据）；本轮只实现森林级，不建空的树级 bucket。
- **校验作用域 = 本批涉及的图**（性能取舍；已知代价见下）。
- **恒跑、无开关**：不受 `skipValidate` 影响；与硬性 `STRUCTURAL_RULES` 的「缺席配置面」一致。
- 判定口径**只留一条**：两边根都能解析且相等才算通过；任一边解析不出即**不判定**（不误报）。
- **树收集收敛**：只保留纯算法 `collectDescendantIds`；数据源与失败策略归各自消费者（导出用例 / `diverge` 调用侧）。
- dev 种子：银图挂进金图树内，**保留**两条引用（仍是「跨子图引用」的种子演示）。
- `isInGraphTree` / `deleteGraphTree` **本次不动** —— `03 I-1` 留待**步骤 07**。

## 已知限制（记录，未处理）

- **作用域逃逸两类**（`U-8` / `U-9`）：违规由本批**引入**、但违规**载体未被本批触碰**时不会被拦（悬空引用随后被挂到别树；`update_graph` 迁移子树使后代引用跨树）。后者在**正常 UI 路径不可达**。已移交**步骤 06**。
- **真正指向森林之外的悬空引用**本步不覆盖 —— 这是「不可解析 → 不判定」口径的代价（结构完整性成为不变量后才可判定）。
- **本地 localStorage 旧数据**不会被自动修正；且旧数据会让相关图的编辑**持续被拒绝**（`U-6`，已移交步骤 06）。
