## 目标（已达成）

把图数据的持久化从 `graph` 层内部抽成**独立层**，并消灭三处静默缺陷。完成后：

- `frontend/src/persistence/` 是**唯一入口**，含四条目：`index.ts`（公开面）/ `coordination/`（跨类别协调）/ `categories/`（每类数据自持键方案与序列化）/ `medium/`（介质）
- 调用方读写图数据**只经 `persistence/`**，不再直接触碰 storage API
- **写失败不再静默**：落盘失败返回可判别结果 + 置 store 的存储错误状态位，UI 有可见提示
- **落盘先行**：先写磁盘、成功后才引用替换内存注册表 —— 消除「内存已前进、磁盘没跟上」
- **介质不静默降级**：介质枚举 / 读取异常上报 `unavailable`，不再冒充空结果

## 已定决策（摘要）

- 分层**按职责划**，不按介质划；介质的选择权收在层内
- 公开 API 用**领域类型**，不用「按键读写」—— 键是介质的 API，不是这一层的 API
- **`categories/` 不知道介质是谁**；介质访问只允许出现在 `medium/`
- **不写数据兼容 / 版本迁移代码**（项目既有策略）
- 本步骤**保持同步签名、只落 localStorage**；异步化与 IndexedDB 留给 P2
- 视图状态**原样搬入**（真正的收编属步骤 04）
- 项目级 `AGENTS.md` 的架构图**只做最小修正**（删失效条目 + 声明「本图暂未收录（待补）」）

## 已知边界（如实记录，未修）

- **P1 无介质事务**：一次提交内已写成功的条目**不撤销**，磁盘可能留下半写态，且下次启动会把它读成基线。**真原子性由 P2 的 IndexedDB 事务兑现。** 该边界已固化进头注释与一条专门的有害子情形测试。
- **失败返回值通道被部分消费**：`commitBatchToGraphs` 的失败返回值在 16 个调用点里只有 5 个消费。
