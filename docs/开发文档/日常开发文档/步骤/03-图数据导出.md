## 目标（已达成）

让用户把**存在 localStorage 里的图数据导出成文件** —— 数据的第一份真实外部副本，同时为未来的 IndexedDB 导入**预先定死格式**。

- 导航面板底部：「**导出**」（可用）+「**导入**」（`disabled` 占位、**零代码**）；原「笔记库 / 常识层 / 设置」三个占位按钮**已删除**
- 点「导出」→ **置顶弹窗**列出全部可导出单位（**每棵根图树一项**）→ 选一项 → **下载一个 JSON 文件**
- **一次只导出一个文件**（用户重复操作导下一棵）—— 借此规避浏览器对「连续多文件下载」的拦截

## 格式（已定死，供未来导入消费）

```text
{ format: 1, graphs: GraphData[] }
```

`format` 为**单调递增整数**；未来加操作日志等字段时**只追加可选字段**，不改既有字段名与类型；**不含视图状态**。

## 已定决策（摘要）

- **导入只留占位**（disabled + title），本轮**不写任何导入代码**
- **一次一个文件**，单位 = 每棵根图树（含全部子图，**自包含**）
- **加格式版本号**（`format: 1`）
- **普通下载**（`Blob` + `<a download>`），**不用** File System Access API
- 弹窗数据源**复用**既有 `listRootGraphInfos()`，不新建读 API
- 子树遍历**留在域层**（`parentGraphId` 链构成森林是域语义），不进 `persistence/`

## 下载可靠性（验证阶段回流补强）

三条约定已落地并各有测试：revoke **必须延后**（同步 revoke 会让部分浏览器静默取消下载且不抛错）；`<a>` **先挂载**再点击后移除；下载函数**捕获异常**并归为 `unknown`。

## 已知限制（记录，未处理）

- **⚠️ 跨树引用不进信封**：`GraphData.nodes` 可含 `sourceGraphId` / `childGraphId`，**可指向树外的图**（dev 种子与 `diverge` 都会产生）。因此「一棵树 = 一份自洽快照」**不成立** —— 未来 import 后这些引用会悬空。
  格式**可向后兼容地扩**（在 `graphs` 里多带图或加可选字段），**但必须在 import 动工前正式裁决**。
- 导出路径上**任一图读取失败即整体失败**（不静默跳过）—— 代价是一张**无关**图损坏也会导致导出失败。取舍为「可见的失败优于静默的不完整」。
