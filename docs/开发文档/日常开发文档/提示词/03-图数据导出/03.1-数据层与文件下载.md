# 03.1 数据层：信封 + 子树遍历 + 文件下载 — 提示词

## 当前状态

- 持久化层已按步骤 02 抽出（`frontend/src/persistence/`，含 `coordination/` / `categories/` / `medium/`），图数据的读入口已可用。
- **仓库中不存在任何文件下载代码**（`Blob` / `createObjectURL` / `<a download>` 全无）。
- `graph/use-case/useNavigation.ts` 已有 `listRootGraphInfos(): RootGraphInfo[]`（列出根图信息，失败会报 `STORAGE_UNAVAILABLE`）—— **本任务复用它，不要新建读 API**。
- `graph/utils/graph_tree.ts` 已有**向上**回溯（`findParentGraph`），**没有向下**收集子树的能力。

## 目标

用户能导出**一棵图谱树**（根图 + 全部子图）为一个 JSON 文件，格式为 `{ format: 1, graphs: GraphData[] }`，经浏览器下载落盘。

**格式必须一次定死**（未来的 IndexedDB 导入要直接消费它）：`format` 为单调递增整数（本步骤为 `1`）；未来加操作日志时**只追加可选字段**，不改既有字段名与类型；**不含视图状态**。

## 具体子任务

### 1.1 数据层：信封与导出负载（`persistence/coordination/export_graphs.ts`）

- 定义信封类型（含 `format`）与「按 id 集合组装导出负载」的公开函数。
- **只产出数据对象**，不碰文件、不碰 DOM —— 存储层不依赖 `Blob` / `URL`，可脱离浏览器测试。
- 图数据经 `categories/graph_data` 读出，**不绕过类别层**。
- 命名诚实：本文件**只做导出**，不得叫 `import_export`（项目规范不容忍名不副实）。
- 经 `persistence/index.ts` 公开（类型与函数一并）。

### 1.2 域层：子树遍历（`graph/utils/graph_tree.ts`）

- 补一个**向下**的遍历：给定根图 id，收集整棵树的图 id 集合。
- **必须留在域层**（`parentGraphId` 链构成森林是域语义，`persistence/` 不该编码它）。
- 需要**环防御**（沿用既有回溯的 `visited` 集合同思路）。
- 不新建引擎 API。
- **⚠️ 索引构建阶段不得静默跳过**：为找出「谁是谁的子图」，遍历需读取每张图的 `parentGraphId`。若某张图在此阶段读取失败（`missing` / `corrupted` / `unavailable`），**无法判断它是否属于目标树** —— 此时**必须让遍历整体失败并回报**，不得跳过。
  **理由**：数据层的不变式是「缺图的导出是不完整副本，比失败更危险」（见 `coordination/export_graphs.ts` 的头注释）。跳过会把「父图损坏 → 其后代整支静默消失」变成一次**不完整却报成功的导出** —— 即数据层守住的原则，在「决定导哪些」的遍历里被违反。
  **已知代价（刻意接受）**：一张**无关**图损坏也会导致导出失败。取舍是**可见的失败优于静默的不完整**。

### 1.3 用例层：编排与文件下载（`graph/use-case/export_graphs.ts`）

- 按项目既有的组合式函数约定（与 `useNavigation` / `useGraphOperation` 同风格）导出公开入口。
- 流程：遍历子树取 ids → 调数据层组装负载 → 序列化 → 触发下载。
- **文件 I/O 留在本层**：`Blob` + `URL.createObjectURL` + `<a download>`。
- **下载必须可靠（本轮补强，见下三条）** —— 当前「同步 revoke + 未挂载 + 无 try/catch」的组合**会让部分浏览器静默取消下载，却仍返回 `{ ok: true }`**，叠加「无成功反馈」即「用户以为导出了、实际没有文件」：
  1. **不得同步 revoke**：`anchor.click()` 后在 `finally` 里立即 `revokeObjectURL` 会让浏览器（证据：Firefox bug 1282407 及多方报告）在异步取 Blob 之前就失去对象 URL → **下载被取消且不抛错**。改为延后 revoke（如 `setTimeout(..., 0)`），**仍须 revoke**（不 revoke 会泄漏）。
  2. **`<a>` 先挂载再点击**：现代浏览器多数容得下未挂载即 `click()`，但成熟做法是「挂载 → 点击 → 移除」，请照此实现。
  3. **下载函数必须捕获异常**：`new Blob` / `createObjectURL` / `click()` 任一抛出，**应在用例层归为 `{ ok: false, reason: 'unknown' }`**，不得穿到调用方的 click handler。若你选择不捕获，则**必须**把 TSDoc 里「不抛异常」的表述改为如实 —— 但优先选捕获。
- 导出失败返回**可判别的失败结果**（与持久化层的结果类型风格一致）。

## 冻结接口（UI lane 并行依赖，**不得改名或改形状**）

```ts
// 数据层（persistence/index.ts 公开）
type GraphExportFormatVersion = 1
interface GraphExportEnvelope { format: GraphExportFormatVersion; graphs: GraphData[] }
exportGraphs(ids: GraphId[]): ReadResult<GraphExportEnvelope>

// 用例层（graph/use-case/export_graphs.ts 公开）
useGraphExport(): { exportGraphTree(rootId: GraphId): ExportResult }
type ExportResult = { ok: true } | { ok: false; reason: 'unavailable' | 'unknown' }
```

- UI lane 会调用 `useGraphExport().exportGraphTree(rootId)`，并用**既有**的 `listRootGraphInfos()` 取列表。
- 若你认为上述形状有问题，**先报告、不要自行改动** —— 改名或改形状会让并行的 UI lane 编译不过。
