# 03.2 导出入口与选择弹窗（UI）— 提示词

## 当前状态

- `frontend/src/components/navigation-card/NavigationPanel.vue`（487 行）是导航卡片的浮层面板：内含根图谱列表（切换 / 行内重命名 / 二次确认删除）与新建表单；**底部一排是三个 `disabled` 的占位按钮**（「笔记库」「常识层」「设置」，`title` 均为「后续阶段」）。
- **仓库中没有通用弹窗组件**：`GraphFloatingWindow.vue` 是节点编辑用的浮空窗（标题卡 + 功能面板 + 双圆钮），**不是通用 modal**。
- **层级现状**：`GraphNavigationCard` 与 `GraphModeSelector` 为 `z-index: 999`，`NotificationPanel` 为 `998`。
- 面板数据源已存在：`useNavigation().listRootGraphInfos()` 返回根图信息列表（失败会报开发者通道 `STORAGE_UNAVAILABLE`）。
- 数据层的导出入口由**并行的另一条 lane** 创建，接口形状已冻结（见下）。

## 目标（用户可见的交互意图）

1. 导航面板底部的那排**换成两个按钮**：「**导出**」（可用）与「**导入**」（**灰色不可用**——以后再做，本轮不实现其任何行为）。
2. 点「导出」→ 打开一个**置顶弹窗**，里面列出**可导出的单位**（每棵图谱树一项，带其标题）。
3. 用户在弹窗里**选中一项** → 该图谱树开始导出为**一个文件**（浏览器下载）→ 弹窗关闭。
4. **一次只能导出一个**（用户重复操作可以导下一棵）—— 这是刻意规避浏览器对「连续多文件下载」的拦截。
5. 没有任何根图时，弹窗内需要一句**空态说明**，不能让用户面对一个空白弹窗。

## 设计约束（编排者会按这些审查）

- **层级置顶**：弹窗必须盖过现有所有浮层 —— 现有最高为 `999`，故弹窗需要**严格高于 999**。
- **受控组件**：弹窗的显隐由父组件（`NavigationPanel`）持有，子组件通过事件向上报「选了哪一项」与「关闭」。**不得**自持显隐状态 —— 项目组件规则是「数据向下流、事件向上流」。
- **不改动该面板的既有部分**：根图谱列表、新建表单、行内重命名、二次确认删除**一律不动**。
- **沿用该面板既有的视觉语言**（它属于导航卡片系，与 `Dock.vue` / `SearchPanel.vue` 同族）；弹窗自身的视觉风格由你决定，只需与既有语言一致。
- **不给「导入」写任何行为**：它就是 `disabled` 按钮 + 一句 `title` 提示（沿用被替换掉的占位按钮那种「后续阶段」措辞风格）。
- **失败反馈走既有通道**：导出失败不要新开提示机制；复用项目既有的通知 / 存储错误通道。
- 代码注释需先读 `FOR-AGENTS/注释资料.md`。
