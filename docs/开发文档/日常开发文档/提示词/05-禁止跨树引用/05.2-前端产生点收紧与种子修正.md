## 当前状态

- `frontend/src/ui/operation_controller.ts` 的 `diverge` 把 `Array.from(graphStore.graphRegistry.keys())`（**全量 registry**）作为 `graphIds` 传给引擎 → 引擎 `findPeerGraph` 在整张注册表里找节点所在图 → **可产生跨树引用**。
- `diverge` **当前无 UI 入口**（`frontend/src/feature-tools/` 中只有类型联合成员 `'diverge'`，无 handler 接线）→ 本任务是**接线前的预防**，不是修线上 BUG。
- 树工具在 `frontend/src/graph/utils/graph_tree.ts`：
  - `isInGraphTree(graph, rootId)`：沿 `parentGraphId` **向上**回溯（祖先从**持久化**惰性读取）。
  - `collectGraphTreeIds(rootId)`：**向下** BFS 收集整棵树（扫描全库建索引；**任一图读取失败则整体失败** —— 该语义是导出场景刻意要求的）。
- 当前树的根 id 可用 `graphStore.graphPath[0]`（由 `graph_store.buildGraphPath` 沿 `parentGraphId` 回溯得到）。
- dev 种子 `frontend/src/dev/bootstrap.ts`：用 `createRootGraph` 建了**两个独立根图** —— `graph-golden`（金牌测试图）与 `graph-silver`（银牌测试图）；金图内有一个引用节点 `sourceGraphId: 'graph-silver'`，银图内有一个引用节点 `sourceGraphId: 'graph-golden'` → 这两个引用**跨树**。银图内另有一个抽象节点 `childGraphId: 'sub-silver'`（同树，合法）。
- **子图创建的既有先例**：同文件的 `sub-silver` 是用 `operations.commitToCurrentGraph([{ type: 'add_graph', graph: { kind: 'subgraph', parentGraphId, ownerNodeId, nodes, edges } }])` 直接建的 —— 本任务沿用这一写法。

## 目标

- `diverge` 的 peer 搜索域 = **当前视图所在图谱树的成员** → 正常路径上不可能产生跨树引用。
- dev 种子修正为**同树跨子图**：银图挂进金图树内，两条引用**保留**，种子仍是「跨子图引用」这一核心功能的可演示样例。
- 「树归属 / 树成员」在 `graph_tree.ts` 内保持**单一实现**。

## 具体子任务

### 1.1 `diverge` 的 peer 搜索域收紧

- 传给引擎 `diverge` 的 `graphIds` 改为**当前视图所在图谱树的图 id 集合**。
- **强约束（三条，缺一不可）**：
  1. **纯内存**求归属 —— registry 在启动时已**全量注册**，不得引入需要处理的 I/O 失败路径，也不得为「枚举失败」新增错误上报通道。
  2. **不得产生第二套**「树归属 / 树成员」实现 —— 统一收敛在 `frontend/src/graph/utils/graph_tree.ts`。若既有两个函数的遍历核心可以共用，请提取单一实现后两处共用；不得另写一份等价遍历。
  3. 不得把「无法确定归属」静默升级为「回退全量 registry」。
- 不新建引擎 API（引擎侧 peer 域的语义不变，仍是「在传入的 graphIds 内找」）。

### 1.2 dev 种子修正（银图挂进金图树内）

- 银图从「独立根图」改为**挂在金图树内的子图**：`parentGraphId` 指向金图；并在金图内放置一个 `childGraphId` 指向银图的**抽象知识节点**，使「父图 ↔ 子图」的树关系自洽。
- 两条引用节点（金→银、银→金）**保留**；修正后二者**同属一棵树** → 仍是「跨子图引用」核心功能的演示。
- 遵循 `dev/AGENTS.md` 的「走用户路径，不自创武功」：子图创建**沿用本文件内 `sub-silver` 的既有写法**（同文件已有先例，不属自创武功）。
- **幂等性不得退化**：仍使用固定 ID，图已存在则跳过注入（`createRootGraph` 的幂等保护思路照旧适用；改用 `add_graph` 后请自行保证等价幂等）。
