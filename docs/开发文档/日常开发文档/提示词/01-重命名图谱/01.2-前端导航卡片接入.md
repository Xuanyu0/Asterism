# 01.2. 前端导航卡片接入 — 提示词

## 当前状态

导航卡片根图谱列表（`frontend/src/components/navigation-card/NavigationPanel.vue`）每行结构为 `[root-item（图标 + 标题 + "当前"徽标）+ 删除按钮]`。"当前"徽标按 `currentRootId` 判定渲染；删除按钮对当前根图谱不渲染，且 `requestDeleteRoot` 内二次拦截（两道防线）。删除按钮样式 `.root-delete-btn`：行悬浮显现、`size-3.5` 图标、flex 布局。图标源为 `@heroicons/vue` outline 24 集（`PencilIcon` 可用，与 `TrashIcon` 同源同风格）。

用例层 `useNavigation.ts` 已有 `createRootGraph`（构造 `graphLevel` 批 + `add_graph` 提交 `commitBatchToGraphs`，recordLog: false）、`deleteRootGraphTree`（直连持久化 + 注册表，不走引擎操作）、`listRootGraphInfos`（返回按标题排序的根图谱列表）。GE 侧 `update_graph` 图级操作已就绪（配套 01.1 提示词）。

## 目标

导航卡片根图谱列表获得"重命名图谱"能力：铅笔更名按钮（删除按钮左侧、视觉风格一致）+ 行内编辑（inline edit）+ 移除"当前"文字徽标；`useNavigation` 新增 `renameRootGraph`（提交 `update_graph` 图级批，进操作日志）；`createRootGraph` 同步接入重名校验。当前根图谱不可删除的两道防线原样保持；更名对当前根图谱允许。

## 具体子任务

### 2.1. 更名按钮与"当前"徽标调整

- 行结构改为 `[root-item + 铅笔更名按钮 + 删除按钮]`。
- 更名按钮图标 = `PencilIcon`（`@heroicons/vue/24/outline`）；样式复用删除按钮模式（行悬浮显现的 opacity 过渡、同尺寸图标、flex 布局与间距）。
- 移除 "当前" 文字徽标的渲染（`current-badge` 相关）；**保留** `.root-item.current` 蓝色高亮（仍区分当前图，仅去文字冗余）。若移除徽标后该 class 无其他用途，`current` class 判定逻辑保留。
- 可见性差异（有意设计，勿改）：更名按钮对当前根图谱**也渲染**（更名允许）；删除按钮对当前根图谱**不渲染**（保持现状）。

### 2.2. 行内编辑（inline edit）

- 新增局部状态：`editingId`（当前编辑行 id）+ `editTitle`（编辑中的标题文本）。
- 交互：点击更名按钮 → 该行标题文本切换为 `<input>`（预填当前标题、自动聚焦）→ Enter 或失焦确认、Esc 取消（编辑态退出，标题恢复显示）。
- 确认逻辑（确认前 trim）：
  - 空名 → 本地拦截，保持编辑态 + 轻量提示（即时反馈，不提交）。
  - 重名 → **不做本地预检**（校验已下沉 GE）：提交后由引擎返回 `TITLE_DUPLICATE` issue → 按 issue 提示 + 保持编辑态。
  - 通过 → 调 `renameRootGraph` → 成功（validation.valid）：退出编辑态 + 刷新根图谱列表；失败：保持编辑态。
- 互斥：进入编辑态时清空删除 armed 态；点击删除时清空编辑态。

### 2.3. renameRootGraph 用例与测试

- `useNavigation.ts` 新增 `renameRootGraph(id, title)`（**返回 ValidationResult，不再自定义 RenameRootResult**）：
  - 防御：从 `graphStore.graphRegistry` 取目标图，不存在 → 构造 `TARGET_NOT_FOUND` issue（targetType 'graph'）**统一写入 `graphStore.lastValidationResult`** 并返回失败 validation（不抛异常）。
  - 构造全量新图 `{ ...当前图, title, updatedAt: undefined }`——**显式剔除 updatedAt**（引擎按"携带值 ?? executedAt"写入：剔除后由引擎写 executedAt 刷新时间戳；逆元快照仍携带旧 updatedAt，undo 时恢复历史时刻）。提交 `[{ kind: 'graphLevel', operations: [{ type: 'update_graph', graph: 新图 }] }]` 至 `commitBatchToGraphs`（**recordLog 默认 true** → 进操作日志；不传 `recordLog: false`）。`commitBatchToGraphs` 内部已写 `lastValidationResult`（引擎校验含 EMPTY_TITLE / TITLE_DUPLICATE）。
  - 返回 `commitBatchToGraphs` 的 validation（统一校验通道，与 `useGraphOperation` 透传风格一致）。
- **移除 `isRootTitleUnique` 与 `RenameRootResult`**（重名/空名校验已下沉 GE，01.1）。`createRootGraph` 移除重名校验接线（GE add_graph 校验兜底），其余行为保持现状（幂等返回逻辑不变）。
- `useNavigation.test.ts` 更新用例：提交构造正确性 / 目标不存在防御（写 lastValidationResult）/ 空名与重名由引擎校验返回 issues（非前端 reason）/ 更名成功后列表按新标题重排。
