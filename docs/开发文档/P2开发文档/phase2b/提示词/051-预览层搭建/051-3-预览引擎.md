## 当前状态

项目中没有统一的预览/模拟层。本步骤新建 `preview_engine.ts`，为 add-edge 工具的 hover 预览提供**完整预览图 + 碰撞判定**能力。

**方案**：clone GraphData 方案——`structuredClone` 当前图 → `applyBatch` 模拟添加边 → 返回预览图 + source/target 碰撞布尔。add_edge 工具拿到预览图后 `syncFromGraphData` 整图渲染。

## 具体子任务

### 1. 新建 `frontend/src/feature-tools/preview/preview_engine.ts`

实现 `previewAddEdge` 函数。

**函数签名**：

```ts
function previewAddEdge(
    graph: GraphData,
    sourceId: NodeId,
    targetId: NodeId,
    kind: 'real' | 'virtual',
    direction: 'directed' | 'undirected',
): {
    previewGraph: GraphData
    valid: boolean
    sourceCollides: boolean
    targetCollides: boolean
}
```

**内部逻辑**：

1. `clone = structuredClone(graph)`
2. 构造 add_edge 操作：`{ type: 'add_edge', edge: { id: generateEdgeId(), graphId: clone.id, source: sourceId, target: targetId, kind, direction, label: '' } }`
3. `result = applyBatch(clone, [addEdgeOp])`
4. `result.validation.valid === false` → 返回 `{ previewGraph: clone, valid: false, sourceCollides: false, targetCollides: false }`
5. `previewGraph = result.graph`（source/target 的 degree 已 +1）
6. 碰撞判定（各自排除对端）：
   - `sourceCollides = hasCollisionAt(sourceId, source.position, previewGraph.nodes, new Map(), new Set([targetId]))`
   - `targetCollides = hasCollisionAt(targetId, target.position, previewGraph.nodes, new Map(), new Set([sourceId]))`
7. 返回结果

**不涉及**：
- 不枚举碰撞邻居节点——只判定 source/target 两端点（用户看到的红色在 source/target 上，不是邻居）
- 不调用 renderer / syncFromGraphData——preview_engine 是纯函数，只产出数据
- 不导出 move / orbit 的预览函数——按 YAGNI 仅实现 add-edge

**架构注释**（JSDoc）：
- 角色：预览层模拟——"如果加了这条边，图会变成什么样，会不会碰撞？"，不实际修改真实图
- 未来扩展：通用 `simulateCollision(graph, registry, operation)` 管道供 move / orbit 使用
