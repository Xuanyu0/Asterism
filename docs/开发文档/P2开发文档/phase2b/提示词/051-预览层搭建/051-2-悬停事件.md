# 051-2 — 悬停事件：提示词

> 拓展自：[051-预览层搭建.md](../../步骤/051-预览层搭建.md) §5.2

## 当前状态

事件转发链路 `cy_interaction.ts → mediator → ToolHandler` 目前只支持 `tap` / `cxttap` / `dblclick`。需要新增 `mouseover` / `mouseout` 事件以支持 hover 预览。

## 具体子任务

### 1. cy_interaction.ts：新增 hover 事件

- `CyInteractionHandlers` 接口新增两个可选回调：`onNodeHovered?(nodeId: NodeId): void` 和 `onNodeHoverOut?(nodeId: NodeId): void`
- `bindCyEvents` 内部新增 Cytoscape 事件绑定：
  - `cy.on('mouseover', 'node', ...)` → 读取 `event.target.id()`，调用 `handlers.onNodeHovered`
  - `cy.on('mouseout', 'node', ...)` → 读取 `event.target.id()`，调用 `handlers.onNodeHoverOut`
- `destroy()` 中对应的 `cy.off` 也要补上

### 2. types.ts：ToolHandler 接口扩展

- `ToolHandler` 接口新增两个可选方法：
  - `onNodeHover?(nodeId: string): void`
  - `onNodeHoverOut?(nodeId: string): void`

### 3. mediator.ts：新增转发方法

- 新增 `onNodeHover(nodeId: string): void` — 转发到 `activeHandler.value?.onNodeHover?.(nodeId)`
- 新增 `onNodeHoverOut(nodeId: string): void` — 转发到 `activeHandler.value?.onNodeHoverOut?.(nodeId)`
- `ToolMediator` 接口同步新增这两个方法的签名

### 4. Graph.vue：事件连接

- `renderer.mount()` 的 handlers 对象中新增：
  - `onNodeHovered(nodeId)` → 调用 `mediator.onNodeHover(nodeId)`
  - `onNodeHoverOut(nodeId)` → 调用 `mediator.onNodeHoverOut(nodeId)`

## 变更边界

**禁止修改**：
- `useRenderer.ts` — renderer API 不变
- `cy_style.ts` / `graph_element_mapper.ts`
- `graphStore` / `uiStore` / `draft_store`
- `toolbar/` 下任何 handler（add_edge 改在 051-4）
- 任何 `.test.ts` 文件
- 除 `mouseover` / `mouseout` 外不做任何 Cytoscape 事件改动
