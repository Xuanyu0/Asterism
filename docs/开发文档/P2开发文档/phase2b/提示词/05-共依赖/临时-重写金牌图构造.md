# 临时：重写金牌测试图构造（graphStore 操作路径）

> 不单独开步骤——临时提示词，放在 3.0-1 提示词同目录。

---

## 背景

当前 `createGoldenTestGraphV2()` 通过工厂函数直接拼装 GraphData → `saveGraph` → `loadGraphToView`，绕过了 `applyBatchToGraph` 的完整 3 阶段流水线（操作前提 → execute → 全局规则）。这导致金牌图的构造路径与用户实际操作路径不一致——用户 deconstruct 走的是 `applyBatchToGraph` 路径，两者产生的数据状态可能存在微小差异。

## 目标

将金牌测试图的构造改为走 graphStore 操作路径：`createRootGraph → applyBatchToGraph(节点) → applyBatchToGraph(边) → applyBatchToGraph(子图)`。银图保持工厂模式（需固定 ID）。

构造代码写在 `frontend/src/dev/bootstrap.ts` 中。

## 架构变更

```
旧：bootstrap.ts → initTestRuntime() → createGoldenTestGraphV2() → saveGraph → loadGraphToView

新：bootstrap.ts 内联构造
      ├─ createRootGraph → loadGraphToView
      ├─ applyBatchToGraph(add_node × 6)
      ├─ applyBatchToGraph(add_edge × 4)
      └─ applyBatchToGraph(add_graph)  ← 子图
```

## 涉及文件

| 文件                               | 操作 | 职责                                                                                                                                                  |
| ---------------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `frontend/src/dev/bootstrap.ts`    | 修改 | 内联金牌图的 graphStore 构造逻辑；银图保持工厂模式                                                                                                    |
| `frontend/src/dev/test_runtime.ts` | 修改 | `initTestRuntime()` 改为空函数或删除（构造逻辑已迁入 bootstrap.ts）；`loadGoldenGraph()` 改为从 `lastActiveRootId` 重载；`loadSilverGraph()` 保持不变 |

## 核心任务

### 任务 1：bootstrap.ts 内联金牌图构造

在 `bootstrapDevTools()` 中，用 graphStore 操作构造金牌测试图：

**Step 1**：创建根图

```
graphStore.createRootGraph('金牌测试图') → rootId
graphStore.loadGraphToView(rootId)
```

**Step 2**：添加 6 个节点（一个 batch）

| 节点      | role      | kind    | form     | label     | 特殊字段                                                                                       |
| --------- | --------- | ------- | -------- | --------- | ---------------------------------------------------------------------------------------------- |
| `node-g1` | knowledge | real    | atomic   | 知识节点A | —                                                                                              |
| `node-g2` | knowledge | real    | atomic   | 知识节点B | —                                                                                              |
| `node-g3` | knowledge | real    | abstract | 抽象节点  | `childGraphId: 'sub-golden'`                                                                   |
| `node-g4` | knowledge | virtual | —        | 虚节点    | `kind: 'virtual'`（无 form）                                                                   |
| `node-g5` | reference | —       | —        | 跳转银牌  | `referenceKind: 'communication'`, `sourceGraphId: 'graph-silver'`, `sourceNodeId: 'sv-node-1'` |
| `node-g6` | knowledge | real    | atomic   | 知识节点C | —                                                                                              |

每个节点需填写全部必需字段：`id`、`graphId`（= `graphView.id`）、`role`、`label`、`abstractionLevel`（= 0）、`degree`（= 0）、`position`（使用原金牌图的坐标）。

**Step 3**：添加 4 条边（单独 batch——节点必须已存在）

| 边         | source  | target  | kind    | direction  |
| ---------- | ------- | ------- | ------- | ---------- |
| `edge-g12` | node-g1 | node-g2 | real    | directed   |
| `edge-g23` | node-g2 | node-g3 | real    | directed   |
| `edge-g46` | node-g4 | node-g6 | virtual | undirected |
| `edge-g51` | node-g5 | node-g1 | real    | directed   |

**Step 4**：创建子图（`add_graph` 信号操作）

构造 `sub-golden` 子图数据（id = `'sub-golden'`，kind = `'subgraph'`，ownerNodeId = `'node-g3'`），包含：

- 2 个节点：`sub-g1`（知识节点A）、`sub-g2`（知识节点B）
- 1 条边：`edge-sg12`（sub-g1 → sub-g2，real directed）

**Step 5**：银图保持工厂模式

```
const silverGraph = createSilverTestGraph()
saveGraph(silverGraph)
```

不需要 `loadGraphToView`（当前视图是金图）。

新增 import：

- `useGraphStore` from `@/graph/graph_store`
- `saveGraph` from `@/graph/graph_persistence`
- `createSilverTestGraph` from `@/dev/test_case_factory`（银图工厂仍需要）
- `NodeId`、`EdgeId`、`GraphId` 类型 from `@my-project/graph-engine`

### 任务 2：test_runtime.ts 适配

- `initTestRuntime()`：改为空函数或删除——构造逻辑已迁入 bootstrap.ts
- `loadGoldenGraph()`：改为从 `lastActiveRootId` 重载当前根图，而非重建
- `loadSilverGraph()`：保持不变
- 移除不再需要的 import：`createGoldenTestGraphV2`、`saveGraph`（如果已迁走）
