### 任务 2：回归测试文件

创建 `frontend/tests/regression/golden-silver.test.ts`（~200 行）。

**Setup**：

```ts
import { setActivePinia, createPinia } from 'pinia'
import { useGraphStore } from '@/graph/graph_store'
import {
    saveGraph,
    loadGraph,
    deleteGraph,
    listRootGraphIds,
} from '@/graph/graph_persistence'
import {
    createGoldenTestGraphV2,
    createSilverTestGraph,
} from '@/dev/test_case_factory'
import { validateGraph } from '@my-project/graph-engine'
```

- `beforeEach`：`setActivePinia(createPinia())` + `localStorage.clear()`
- `afterAll`：`localStorage.clear()`

**测试套件 1 — 数据完整性**：

- 金牌图通过 `validateGraph`（valid === true）
- 银牌图通过 `validateGraph`

**测试套件 2 — Store 加载**：

- `saveGraph(golden) + loadGraphToView(golden.id)` → `graphView` 不为 null
- `graphView.nodes.length` === 6（金牌图 6 个节点）
- `graphView.edges.length` === 4（金牌图 4 条边）
- `graphPath` 长度 === 1（根图路径只有自身）

**测试套件 3 — 原子操作链路**（在金牌图上执行）：

- `applyBatchToGraph` + add_node（实节点）→ 节点数从 6 变为 7
- `applyBatchToGraph` + delete_node（无关联边的孤立节点）→ 节点数从 7 变为 6
- `applyBatchToGraph` + delete_node（有出边的节点，含级联）→ 节点数和边数同时减少
- `applyBatchToGraph` + add_edge（有向实边）→ 边数 +1
- `applyBatchToGraph` + move_node → 目标节点 position 更新

**测试套件 4 — fold/expand + undo**：

- `applyBatchToGraph` + collapse_dependency（在 3 节点链式 DAG 上）→ cognitiveState.foldedDependencies 长度 > 0
- `undo()` → 恢复到折叠前状态（cognitiveState.foldedDependencies 为空或 undefined）
- 非法操作（delete 不存在的节点）→ validation.valid === false，graphView 不变

**测试套件 5 — 持久化**：

- `saveGraph(golden) + loadGraph(golden.id)` → 返回的节点数 === 原始节点数
- `deleteGraph(golden.id) + loadGraph(golden.id)` → 返回 null
- `listRootGraphIds()` 包含金牌图 ID（`graph-golden`）

**约束**：

- 不得测试 engine 已覆盖的纯函数路径（`applyBatch` 单步操作正确性、validateGraph 规则拦截、不可变性检查）
- 所有测试数据通过 `dev/test_case_factory.ts` 构造，不重复造数据
- 每个测试用例之间独立，通过 `beforeEach` 清空状态

## 不确定事项

> **Q1**：`dev/test_case_factory.ts` 中 `createSilverTestGraph` / `createGoldenTestGraphV2` 内部调用了 `saveGraph`（持久化子图到 localStorage）。方案：每次测试前 `localStorage.clear()` 确保隔离。

> **Q2**：`graph_store` 依赖 Pinia。方案：通过 `setActivePinia(createPinia())` 在测试 setup 中初始化，此为 Vue 生态标准测试模式。不依赖 Vue 组件树。
