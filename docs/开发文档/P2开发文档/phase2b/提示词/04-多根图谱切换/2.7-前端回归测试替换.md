#### 公共设置（每个文件的 beforeEach）

```ts
import { describe, it, expect, beforeEach } from 'vitest'
import { setActivePinia, createPinia } from 'pinia'
import { useGraphStore } from '@/graph/graph_store'
import { saveGraph } from '@/graph/graph_persistence'
import { createGoldenTestGraphV2 } from '@/dev/test_case_factory'

beforeEach(() => {
  setActivePinia(createPinia())
  localStorage.clear()
  const golden = createGoldenTestGraphV2()
  saveGraph(golden)
  const store = useGraphStore()
  store.loadGraphToView(golden.id)
})
```

不重复导入——各文件根据需要用 `useGraphStore()` / `useUIStore()`。

#### 2.1 `add-node.test.ts`

导入 `useAddNodeTool` from `@/feature-tools/toolbar/add-node`。测试：

- **激活后 isActive 为 true**：`handler.activate()` → `expect(handler.isActive).toBe(true)`
- **onCanvasClick 创建 DraftNode**：`handler.onCanvasClick({ x: 100, y: 200 })` → `expect(handler.draftNode).not.toBeNull()`，检查 `draftNode.x`、`draftNode.y`、`draftNode.kind` 正确
- **onConfirm 提交节点到 store**：设置 draft → `handler.onConfirm('测试标签', '摘要')` → `expect(store.graphView!.nodes.length).toBe(7)`（金牌图原有 6 个）
- **空 label 拒绝**：设置 draft → `handler.onConfirm('', '摘要')` → `expect(store.graphView!.nodes.length).toBe(6)`（不变），检查 `store.lastValidationResult.valid` 为 false
- **deactivate 清除草稿**：设置 draft → `handler.deactivate()` → `expect(handler.draftNode).toBeNull()`，`expect(handler.isActive).toBe(false)`
- **onCancel 清除草稿**：设置 draft → `handler.onCancel()` → `expect(handler.draftNode).toBeNull()`

#### 2.2 `add-edge.test.ts`

导入 `useAddEdgeTool` from `@/feature-tools/toolbar/add-edge`。测试：

- **激活后 isActive 为 true**：`activate()` → `isActive === true`
- **首次 onNodeClick 记录 source**：`onNodeClick('node-g1')` → `highlightNode === 'node-g1'`
- **两次 onNodeClick 添加边**：`onNodeClick('node-g1')` → `onNodeClick('node-g6')` → `expect(store.graphView!.edges.length).toBe(5)`（金牌图原有 4 条边）
- **添加成功后重置 source**：两次点击添加成功 → `expect(handler.highlightNode).toBeNull()`
- **第二次可继续加边**：`onNodeClick('node-g1')` → `onNodeClick('node-g6')` → 边数 5 → 再 `onNodeClick('node-g1')` → `onNodeClick('node-g2')` → 边数 6
- **deactivate 清空 source**：`onNodeClick('node-g1')` → `deactivate()` → `highlightNode === null`，`isActive === false`
- **cursorClass 变化**：未选源节点时为 `cursor-crosshair`，选了源节点后为 `cursor-cell`

#### 2.3 `delete.test.ts`

导入 `useDeleteTool` from `@/feature-tools/toolbar/delete`。测试：

- **激活后 isActive 为 true**
- **首次 onNodeClick 标记待定**：`onNodeClick('node-g1')` → `highlightNode === 'node-g1'`
- **两次点击同一节点确认删除**：`onNodeClick('node-g1')`（标记）→ `onNodeClick('node-g1')`（确认）→ `expect(store.graphView!.nodes.length).toBe(5)`（6→5）
- **删除节点级联删除关联边**：删除 `node-g3`（是 edge-g23 的 target）→ `expect(store.graphView!.edges.length).toBe(3)`（4→3 因为 edge-g23 被级联移除）
- **两次点击不同节点切换目标**：`onNodeClick('node-g1')` → `highlightNode === 'node-g1'` → `onNodeClick('node-g2')` → `highlightNode === 'node-g2'`
- **deactivate 清空 pending 状态**：`onNodeClick('node-g1')` → `deactivate()` → `highlightNode === null`，`isActive === false`
- **notification 状态**：未标记时 `notification === null`，标记后 `notification.visible === true`

#### 2.4 `fold.test.ts`

导入 `useFoldTool` from `@/feature-tools/toolbar/fold`。测试：

- **激活后 isActive 为 true**
- **onNodeClick 折叠节点**：`onNodeClick('node-g2')` → `expect(store.graphView!.cognitiveState?.foldedDependencies.length).toBeGreaterThan(0)`
- **再次点击同一节点展开**：折叠 `node-g2` → 再点击 `node-g2` → `foldedDependencies.length === 0`
- **折叠非依赖节点不改变 foldedDependencies**：折叠其他节点（无折叠依赖项的节点）→ `foldedDependencies.length` 不变
- **deactivate 取消激活**：`deactivate()` → `isActive === false`

#### 2.5 `tests/mediator.test.ts`

导入 `useToolMediator` from `@/feature-tools/mediator`，以及各工具的工厂函数。测试：

- **获取单例**：两次调用 `useToolMediator()` 返回同一实例
- **注册 handler 后可激活**：注册一个 handler → `activate('add-real-node')` → `activeToolId === 'add-real-node'`，`activeHandler` 不为 null
- **激活新工具自动取消旧工具**：先激活 A → 再激活 B → A 的 `isActive` 为 false，B 的 `isActive` 为 true
- **activate(null) 取消所有**：激活一个工具 → `activate(null)` → `activeToolId === null`
- **deactivate 取消**：激活一个工具 → `deactivate()` → `activeToolId === null`
- **事件转发到 activeHandler**：注册一个 mock handler → 激活 → `onCanvasClick` → mock handler 的对应方法被调用
- **onRightClick 取消活跃工具**：激活工具 → `onRightClick()` → `activeToolId === null`
