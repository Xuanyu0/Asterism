# Phase 2b — Step 050：渲染/交互层重构

> 严格去 Cy 耦合的架构调整。背景：3.0-4 的 move_node 拾取放置暴露了"Cy 只是渲染层"规则的临时例外——工具直接 import `getCyInstance()` 操作 Cy 实例，渲染层边界模糊。本轮重构建立明确的渲染/交互层封装边界。

**前置来源**：[05-步骤-共依赖.md](05-步骤-共依赖.md) §3.0-5

---

## 已确认决策

1. **Cy 的角色重新定位为"交互层 + 渲染层"**（不再单称"渲染层"）。
   - Cy 实际承担两件事——`cy.json()` + stylesheet 负责视觉渲染，`tap`/`cxttap`/`dblclick` 事件负责用户手势捕获。

2. **目录重命名**：`frontend/src/render/` → `frontend/src/cytoscape/`。表达"此目录是 Cy 外部库的严格隔离层"的架构意图——所有直接依赖 `cytoscape` 的代码集中在此目录，目录外不可见。

3. **术语替换**：后续开发中不再使用"投影"（`mapNodeToCyElement` 的字段挑选本质上不是投影），替代为：
   - **映射**（mapping）：GraphData 字段 → CSS class 的语义转换（如 `role + kind → ['node-knowledge', 'node-atomic']`）
   - **拷贝**（copy）：GraphData 字段原样写入 Cy `data`

4. **Cy 的 `data` 仅存放渲染所需的最小字段**：`id`、`label`。现有 `CyNodeData` 中的 `role`、`kind`、`form`、`degree`、`abstractionLevel` 在 `getNodeClasses` 消费完后不再进入 Cy `data`。

5. **严格去耦合**：`cytoscape/` 目录之外禁止 `import` 以下任一：
   - `getCyInstance()` / `getInstance()`（已删除）
   - `import cytoscape from 'cytoscape'`
   - `import type { Core } from 'cytoscape'`

6. **renderer 对外暴露语义方法**：工具通过 `renderer.setNodePosition()` / `renderer.addNodeClass()` 等高层方法操作视觉，不直接接触 Cy 实例。

7. **syncFromGraphData 时清除全部 transient 状态**：防御性设计——将"操作期间不改 GraphData"的隐式契约变为显式约束。

8. **高亮走反应式逻辑**：renderer 暴露 `bindHighlight(getter, className)`，内部用 `watch(getter)` 自动管理 class 切换。

## 架构总览（调整后）

```
cytoscape/
  ├── use_cytoscape_renderer.ts   — 渲染生命周期 + 语义 API
  ├── graph_interaction.ts         — Cy 事件 → 语义事件（纯函数，非组合式）
  ├── graph_element_mapper.ts      — GraphData → Cy elements（独立纯函数）
  └── cytoscape_style.ts           — stylesheet

GraphData (唯一事实源)
    │
    ▼
graph_element_mapper.ts（纯函数映射 + 拷贝）
    │  GraphData 字段 → CSS class（语义映射）
    │  id / label / position / classes（最小拷贝）
    ▼
use_cytoscape_renderer.ts（渲染层）
    │  ┌ syncFromGraphData(graphData)     — 内部调 mapper + cy.json() + 清 transient
    │  ├ revealElement(id)                — 视口定位 + 闪烁（不变）
    │  ├ setNodePosition(id, pos)         — 视觉预览位置
    │  ├ addNodeClass / removeNodeClass   — 视觉预览样式（只走 stylesheet）
    │  ├ bindHighlight(getter, className) — 反应式外部高亮
    │  ├ trackCursor(callback)            — 光标追踪 → 模型坐标
    │  ├ clearAllPreviews(owner)          — deactivate 时清理
    │  └ 内部管理 transient 视觉状态（按 owner 命名空间隔离）
    │
    ▼
Cy 实例（仅 cytoscape/ 内部可见，外部零 import）
    │
    ├── 视觉渲染（cy.json + stylesheet）
    └── 事件捕获（tap/cxttap/dblclick — 通过 graph_interaction.ts 翻译）
            │
            ▼
graph_interaction.ts（纯函数 bindCyEvents）
    Cy 事件 → 语义事件（onNodeClick / onEdgeClick / onRightClick / onNodeDoubleClick）
            │
            ▼
mediator.ts（事件路由，不变）
    语义事件 → 活跃 handler
            │
            ▼
工具 handler（业务逻辑，不变）
    构造 operation → graphStore.applyBatch
    视觉预览需求 → renderer 语义方法
```

### renderer 新增 API 详单

```ts
// 数据同步
syncFromGraphData(graphData: GraphData): void

// 视口控制（不变）
revealElement(elementId: string): void

// 视觉预览：位置
setNodePosition(nodeId: string, pos: { x: number; y: number }): void
getNodePosition(nodeId: string): { x: number; y: number } | null

// 视觉预览：样式 class（仅走 stylesheet，带 owner 命名空间）
addNodeClass(nodeId: string, className: string, owner: string): void
removeNodeClass(nodeId: string, className: string, owner: string): void
clearAllPreviews(owner: string): void

// 反应式外部高亮（内部用 watch）
bindHighlight(getter: () => string | null | undefined, className: string): void

// 光标追踪（内部管理 DOM mousemove 绑定/解绑 + 坐标转换）
trackCursor(callback: (modelPos: { x: number; y: number }) => void): { stop(): void }
```
