# Asterism

## 这个项目是什么

这个项目受图论模型启发制作的一款对知识获取或者学习进度可视化的工具

旨在：

- 让错综复杂的学习路径变得清晰可见
- 让未知的知识清晰的显示在图谱上
- 并用清晰的可视化关系呈现已经掌握的知识以及它们之间的关系

## 这个项目开发的怎么样了

目前这个项目已经实现了部分计划中的功能特性（参照`docs/设计/`下的文档）
现在还是处在试验阶段，可能具有以下缺陷：

- 无法长期稳定存储用户数据
- 数据无法多设备同步
- 交互不流畅
- 用户数据在未来更新后不可用（数据结构变动）

## 我怎么体验这个项目

### 在线体验

项目部署在 Vercel，无需安装任何东西，浏览器直接打开：

<在线地址待部署完成后填写，例如 https://asterism.vercel.app>

### 本地运行体验

需要 Node.js（>= 22.12.0）与 pnpm（11.4.0），在项目根目录执行：

```bash
pnpm install
pnpm dev
```

然后浏览器打开终端提示的地址（默认 http://localhost:5173）。

### 体验提示

- 所有图谱数据保存在当前浏览器的 localStorage 中，不会上传服务器
- 数据无法跨设备同步，不同浏览器之间互不可见
- 项目仍处于实验阶段，数据可能在后续版本更新后不可用
