## composables/ 文件夹的定义

* 存放**通用** vue 组合式函数

## 关于判断 vue 的一组代码拆分的标准

```
这组 ref + 函数 → 服务于一个模板区域吗？
    ├─ 是 → 移入该区域的子组件（.vue）
    └─ 否 → 这组逻辑有渲染标记（DOM 模板）吗？
              ├─ 有 → 留在编排器（它是"胶水"，绑定多个子组件）
              └─ 无 → 拆为 composable（useXxx.ts）
```

## composable 的 JSDoc 规则

- **公开 API 函数**（return 对象中的属性值）→ 必须有 JSDoc
- **内部工具函数**（不 export、不在 return 中暴露）→ 不写 JSDoc，放在内部调用方旁

理由：视觉上一眼分出哪些是外部使用者关心的接口（有注释）、哪些是实现细节（无注释）。避免混淆导出函数和内部函数。
