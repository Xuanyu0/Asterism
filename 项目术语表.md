# 项目术语表

> 本表服务对象：项目日常交流（对话、评审、文档讨论）中的通用术语。
>
> 与另两表的区别：`docs/设计/设计术语表.md` 记录 L1 设计概念；`docs/开发文档/开发术语表.md` 记录代码标识符；本表记录**跨领域通用交流术语**，不限定出处。

## 编写规则

1. **字段格式**：每行统一为 `中文 | 英文 | 含义` 三列。
2. **不限定出处**：术语可来自设计文档、代码、开发讨论或交流约定，不强制标注来源。
3. **用途**：统一项目交流口径，避免同一概念在对话中出现多个叫法。

## 术语表

| 中文            | 英文                                                         | 含义                                                    |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| 唯一事实源      | Single Source of Truth, `GraphData`                          | 所有图数据只存在一个地方                                |
| 单向数据流      | unidirectional data flow                                     | UI → Controller → Engine → Store → Renderer            |
| Cytoscape 边界  | Cytoscape boundary                                           | cy 不修改 GraphData、不持有引用、不保存业务状态        |
| 引擎            | GraphEngine, `@my-project/graph-engine`                      | 框架无关的纯函数状态迁移运行时                          |
| 语义事件        | `onCanvasClicked`, `onNodeClicked`, `onEdgeClicked`（拖拽用 `onDragEnd`） | Cytoscape 原始事件 → 语义化回调                        |
| 学习状态        | learning state                                               | GraphData 表达的学习者当前认知状态                      |
| 认知演化        | cognitive evolution                                          | 通过认知操作改变知识结构的系统行为                      |
| 位置持久化      | position persistence                                         | GraphData.position 是唯一位置事实源                     |
| 本地优先        | Local First                                                  | MVP 阶段只用 localStorage，不依赖后端                   |
| 禁止拾取        | `autoungrabify`                                              | Cytoscape 配置项：`true` = 禁止所有节点拾取放置         |
